Plot

Group: Sinks. Type: PnPlot.

Sink that plots a whole vector arriving in a single message. It is the vector-fed sibling of the Graph node: where Graph time-bins individual scalar values by their wall-clock arrival — so a plot only fills in as real time passes — Plot takes the entire dataset at once (a $pnvector on data/value, the same snapshot path the Oscilloscope uses) and distributes its elements across the X axis immediately. The plot is therefore filled and deterministic the instant a vector arrives, which makes the Error bars draw-style — a box-and-whisker per bucket — easy to drive from a Ramp (with a little jitter) instead of waiting hours on a live feed. Plotting is done with PLplot, reusing Graph's renderers so every draw-style looks identical.

Vector → buckets

The N elements of the incoming vector are distributed across M consecutive X-buckets, where M is the x-buckets setting. Bucket b owns the half-open element range [b·N/M, (b+1)·N/M) and aggregates that whole run into a real count, mean, standard deviation, minimum and maximum — exactly the running totals Graph keeps per time bucket. The time-series view then draws one glyph per bucket. With the Error bars style each bucket becomes a box-and-whisker, so fewer buckets (a few dozen elements each) give genuinely fat spreads, while pushing x-buckets up toward the vector length collapses to about one element per bucket — at which point the whiskers reach halfway toward the neighbouring buckets' means so the single-sample buckets still trace a continuous band rather than a row of disconnected dashes.

The most recent vector is retained, so changing x-buckets re-bins the same data live without waiting for a fresh message. A bare scalar value carries no spread to bucket, so scalars are ignored — use a Graph for scalar time-series.

PropertyDescription
value-key Data-bag member holding the vector to plot (default value, i.e. data/value — the universal slot a Ramp emits its $pnvector on). Only a vector value is a dataset; scalar values under this member are ignored.
x-buckets How many buckets the vector is distributed across along the X axis (2–200, default 16). Each bucket aggregates its run of elements into a count, mean and spread, and the time-series view draws one point per bucket (or, with the Error bars draw-style, one box-and-whisker). Fewer, wider buckets fold more elements together for a fuller spread per error bar; setting the count near the vector length collapses to about one element per bucket. Has no effect on the distribution view, which bins by value rather than by position.
data-view What the plot represents. Time series (default) draws one glyph per X-bucket (the X axis is the bucket index). Distribution bins the vector's elements by value into 40 fixed-width bins and plots how often each value occurs (X axis is value, Y axis is the count) — the shape reads as a histogram of the vector. Bin edges auto-range over the vector's [min, max].
draw-style How the chosen data-view is drawn (the “Draw as” setting): Points marks each bucket with a filled circle, Lines connects the bucket means with a polyline, Bars draws each as a filled bar from the baseline, and Error bars (default) draws each bucket as a box-and-whisker.

For the Error bars style the whisker spans the bucket’s minimum…maximum element and the box is centred on the mean, spanning ± 1 standard deviation. Each box is filled green when its mean rose versus the previous bucket and red when it fell, so the trend reads at a glance; the first bucket and any flat step are drawn neutral grey. In the distribution view (where there is no per-bucket spread) the style falls back to bars.

line-color Colour of the plotted data — the polyline, the point markers, or the bar fill, depending on draw-style. Defaults to a dark blue that reads well against a white background.
line-width Stroke width of the data polyline, in pixels (1–8, default 2). Also scales the marker size of the Points draw-style.
axis-color Colour of the plot frame, ticks, and tick labels. The same colour is used for the thin frame painted around the plot rectangle.
background-color Fill colour of the plot rectangle behind the data. Defaults to white.
show-grid When enabled, draws a thin grid through every major tick on both axes for easier reading of values.
log-y Plots the Y axis on a base-10 logarithmic scale. Honoured in the distribution view, useful for long-tailed distributions whose tallest bars would otherwise crush the smaller ones flat.
y-from-zero Anchors the Y axis at zero instead of auto-fitting it tightly around the data. Honoured in the time-series view on a linear axis.

In the node's settings dialog these properties are split across two tabs: Appearance collects how the plot is drawn (draw-style, line-color, line-width, axis-color, background-color, show-grid), while Data collects what is plotted and how the value axis is framed (value-key, x-buckets, data-view, log-y, y-from-zero).
