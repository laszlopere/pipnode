Clock Divider

Group: CPU. Type: PnClockDivider.

Turns one tick stream into several slower ones. It has two inputs and a configurable number of outputs, each with its own divisor. Every message on the tick input adds one to a shared count; an output forwards that tick message when the count is a multiple of its divisor. With the default divisors 2, 4, 8, 16:

Tick/2/4/8/16
1————
2fires———
3————
4firesfires——
8firesfiresfires—
16firesfiresfiresfires

So one Auto Trigger ticking every second can drive a chain that runs every 2 seconds, another every 4, and so on. The divisors do not have to be powers of two: 60 on a one-second tick gives a once-a-minute output. A divisor of 1 forwards every tick. Each output is labelled with its divisor on the worksheet (/2, /4, ...).

A message on the reset input sets the count back to zero and sends nothing, so every output starts its division again from the next tick.

When several outputs fire on the same tick, the one with the largest divisor fires first and the one with the smallest last (equal divisors fire from the highest output down). A multi-input node such as Calculator 2 that computes on the fastest output therefore already sees what the slower outputs just sent.

PropertyDescription
outputs Number of outputs, 2–16. Default 4. Lowering it keeps the divisors of the removed outputs, so raising it again brings them back; wires on outputs that no longer exist stop carrying messages.
divisors One divisor per output, 1–1000000, edited in the settings dialog. Saved as a JSON array such as [2,4,60]; outputs the array does not reach use the default 2, 4, 8, ... for their position.

The count is runtime state: it is not saved with the worksheet, so a reopened worksheet starts counting from zero.
