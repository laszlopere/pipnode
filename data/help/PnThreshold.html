Threshold

Group: Filters. Type: PnThreshold.

Schmitt-trigger comparator. Watches the numeric value of each incoming message, tracks a single on/off state, and forwards a message only when that state changes. The forwarded message keeps its topic, id and other members, but its value is rewritten to 1.0 (state on, at or above the threshold) or 0.0 (state off, below it), so downstream nodes always see a clean boolean — the same 0.0/1.0 encoding the rest of Pipnode uses for on/off.

The state turns on the moment value reaches threshold. It turns off again only once value has fallen a full hysteresis below the threshold — that is, below threshold − hysteresis. Readings inside the [threshold − hysteresis, threshold) band leave the state unchanged, which is what stops a noisy signal hovering near the trip point from flapping the output. With hysteresis left at 0 the node degenerates to a plain “value ≥ threshold” comparator that emits on every crossing.

The first message that carries a numeric value establishes the initial state (on if at or above the threshold, off otherwise) and is always forwarded, since there is no earlier output to compare it to. Messages without a numeric value are ignored and leave the state untouched.

PropertyDescription
threshold Value at or above which the output is on (1.0).
hysteresis How far below the threshold the value must fall before the output turns off again. Zero disables hysteresis.
