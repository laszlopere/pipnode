Injector

Group: Sources. Type: PnInject.

Manual source. Emits a single message carrying the configured text in data.output whenever it is fired (typically by clicking the node's fire button on the worksheet). While the text is empty the node enters a red “configuration required” state and firing is a no-op.

PropertyDescription
text The string injected as data.output.
value Number injected as data.value.
success Boolean placed in data.success so downstream filters can react to either branch.
