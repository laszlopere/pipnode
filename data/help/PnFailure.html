Failure

Group: Filters. Type: PnFailure.

Pass-through filter that forwards a message only when its mandatory data.success boolean is false. Messages whose success member is missing or not a boolean are dropped.

The mirror of Success: feed both filters from the same upstream to split the stream into a "good" branch and a "bad" branch without configuring any rules. Typical uses are alerting on a failed Ping, routing an HTTP error to a notification sink, or counting failures separately from successes through Stats.
