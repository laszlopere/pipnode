Label

Group: Sinks. Type: PnLabel.

Shows the text of an incoming message on a small styled panel — the text counterpart of the Digital Clock. Each message's output member is read as a (possibly multi-line) string and the node displays its last one or two lines, like a live tail of a log or of a command's output. An escaped newline (a literal \n) is treated as a line break, and a message that carries no output string blanks the label.

On the worksheet the client area is a fixed magnified view of the same readout the XFCE panel applet mirrors — always exactly the Digital Clock's size, so it never resizes with the data. The box, its padding and the font are all sized as fractions of the client area, so the worksheet node, the panel-layout preview and the live panel widget are the same readout at three scales. The font keeps its size regardless of text length; a line too long to fit is cropped on the right (its beginning stays visible). Being a sink, the node never forwards a message.

Like the Switch, LED and Digital Clock nodes, a Label snapped onto a worksheet's panel band is mirrored to a live readout in the panel applet, so the same text appears on the desktop panel (fitted to the panel row, and cropped past a maximum width so it never stretches the panel).

SettingDescription
lines How many trailing lines of the output to show — the last line (1) or the last two (2).
alignment Horizontal alignment of the text within the box: Left, Center or Right.
font-family Read-only. The text uses the desktop's default font, so it matches the panel clock.
font-scale Read-only. The text fills the box (a fixed percentage of each line's share of the client area), so every rendering — worksheet, panel preview, live panel — shows it at the same proportion.
weight Read-only. Font weight, fixed at Semi-Bold to read like the panel clock.
italic Read-only. Italic style (off).
text-color Colour of the text — a soft off-white by default.
background-color Fill colour of the box behind the text — a dark slate by default. Set its alpha to zero for a transparent label.
