Chat

Group: Sinks. Type: PnChat.

Sink and source. Displays a scrolling list of chat bubbles in its body, with a single-line entry strip and an inline Send button along the bottom edge. Geometry mirrors Graph and Table: a 280 px standard header sits on top, and a separately-painted body of the same width hangs below it, so a row of mixed Graph / Table / Chat sinks lines up cleanly on the worksheet.

Each incoming message becomes one bubble. The bubble's text is read from the message's data bag at the configurable text-path (default data/output) and the sender label is read from sender-path (default data/from_long_name) — the defaults match the envelope Meshtastic emits, so wiring a Meshtastic node into a Chat works out of the box. The sender label is shown above its bubble and hashed into the bubble's pastel fill colour, so two messages from the same sender always paint the same colour. Bubbles whose source is the chat node itself (sent locally) are right-aligned in the configurable me-color.

Clicking the entry rectangle focuses the chat for keyboard input — a blinking caret appears in the entry, and the worksheet routes printable characters, Backspace, Delete, Enter and the cursor keys into the draft buffer. Pressing Enter (or clicking the inline Send button) emits a fresh message on the chat's output port, with the typed text under data/output, the user's me-name under data/from_long_name, and topic set to whatever the chat node's PnNode topic template resolves to (the per-node Topic field in the settings dialog, defaulting to /pnode/Chat/${nodename}); the same text is also pushed into the local history as a "mine" bubble. Pressing Escape, or clicking anywhere outside the entry strip, ends the typing session without sending. The entry strip is fully canvas-resident — there is no floating GtkEntry widget. Clicking the bubbles area above the entry strip lifts the chat into the standard centred zoom overlay (the same animation the Graph and Table nodes use); while zoomed, the mouse wheel scrolls back through the history.

PropertyDescription
text-path JSON pointer (“/”-separated) resolved against the incoming message to extract the bubble's text payload. Defaults to data/output.
sender-path JSON pointer resolved against the incoming message to extract the sender label. The label is shown above the bubble and hashed into the bubble's pastel fill colour. Defaults to data/from_long_name.
me-name Display name attached to messages the user sends from this node. Stamped under data/from_long_name on every outgoing message and shown above the right-aligned “mine” bubbles in the local history. Defaults to Me.
limit Maximum number of bubbles kept in the history buffer (1–1000, default 200). Older bubbles are dropped from the top as new ones arrive.
background-color Fill colour of the chat body rectangle behind the bubbles and entry strip.
border-color Colour of the body frame, the bubble outlines, and the separator between the entry and the Send button.
text-color Colour of the bubble text and (at lower alpha) the sender label.
me-color Fill colour of the right-aligned bubbles representing messages the user sent from this node.
input-background-color Fill colour of the entry strip rectangle along the bottom edge of the chat body.
send-button-color Fill colour of the inline Send button at the right end of the entry strip.
