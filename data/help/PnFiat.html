Fiat Converter

Group: Filters. Type: PnFiat (subclass of PnHttp).

National-currency converter. For every received message the node multiplies data.value by its cached conversion factor (from → to) and forwards the message with the converted amount, the factor itself in data.rate, the destination currency code in data.currency and a data.deprecated boolean. Non-numeric or missing data.value fields are left untouched so the message still passes through.

This is the fiat sibling of the FX Converter, and writes exactly the same message members — a chain built around one converts to the other by swapping the node. What differs is where the rate comes from. The FX Converter asks CoinGecko for a crypto market price; this one asks Frankfurter for the European Central Bank's daily reference rates, which are authoritative for fiat, need no pivot currency (any member of the set can be the base) and are fixed once per working day rather than moving by the second.

data.deprecated is true whenever the cached rate cannot yet be trusted for the current pair — before the first successful fetch, immediately after the from/to pair is changed (which drops the cached timestamp at once), or after a failed fetch. While deprecated the node still converts using the last known rate so chains do not stall, but it paints the standard error marker on the canvas and surfaces the reason through status and the per-node log.

The fetched rate and the timestamp of the last successful fetch round-trip through the worksheet on save/load, so re-opening a flow does not fire a fresh request: the previously-saved rate is used until the next periodic tick.

PropertyDescription
url Endpoint base URL. The node appends ?base=…&symbols=… at request time. Defaults to Frankfurter's free, key-less latest endpoint; the server is self-hostable, so this can be re-pointed at your own instance.
from Source currency. Pick from the 30 currencies the ECB publishes a daily euro reference rate for: AUD, BRL, CAD, CHF, CNY, CZK, DKK, EUR, GBP, HKD, HUF, IDR, ILS, INR, ISK, JPY, KRW, MXN, MYR, NOK, NZD, PHP, PLN, RON, SEK, SGD, THB, TRY, USD and ZAR. The settings dialog spells each name out beside its code. Crypto assets are not in this set — those belong to the FX Converter.
to Destination currency. Same set as from; when from equals to the node is marked as needing configuration and skips its fetches.
rate Cached conversion factor (1 unit of from equals rate units of to). Defaults to 1 and is overwritten on every successful fetch; persisted with the worksheet.
last-update ISO-8601 timestamp of the last successful fetch, shown read-only in the dialog (“Never” until the first fetch lands). Cleared the instant the pair changes. Persisted with the worksheet alongside rate.
status Read-only outcome of the most recent fetch: Never updated, OK (reference rate of 2026-09-11) — the working day the rates were fixed on, which is not the day you fetched them if you fetched over a weekend — or Update failed: … with the reason. The matching detail is also written to the per-node log.
period Seconds between rate refreshes. Defaults to 3600 (one hour, which is also the highest value the auto-trigger accepts), and the floor is 600: attempts to set a smaller value — from the dialog or by hand-editing a saved worksheet — are silently rounded back up. There is nothing to gain from a faster poll, as the reference rates change once per working day.

Wire one in after any node that emits a numeric data.value with from = EUR, to = HUF to turn a price in euros into forints before it reaches a Debug, Numeric or Graph sink.
