Reduce

Group: Filters/Vectors. Type: PnReduce.

Folds a vector down to a single scalar — the dual of Ramp and the worked-example consumer of Pipnode's vector machinery. It reads value: when that is a $pnvector the node resolves the whole buffer and collapses it to one number per its mode, then overwrites value with that scalar and forwards the message. This re-enters the scalar world the rest of a flow lives in, so the result can drive a Knob readout, an LED, a Switch gate or any gauge.

A plain scalar value passes through as a one-element fold (sum = mean = min = max = first = last = the value; count = 1), so the node never errors on ordinary scalar traffic. A message carrying neither a number nor a vector under value is dropped.

PropertyDescription
mode Which fold collapses the vector: sum, mean, min, max, range (max − min), count (the number of elements), product, stddev (population standard deviation), first or last.
