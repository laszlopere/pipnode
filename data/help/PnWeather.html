Weather

Group: Network. Type: PnWeather.

Auto-triggered source that polls the current weather for a named place from Open-Meteo, a free, key-less API. It is a specialised Http Client: each tick first resolves the configured city to latitude/longitude through Open-Meteo's geocoding endpoint (the result is cached until the city changes), then fetches the forecast for those coordinates. Because that is two requests rather than one, the node overrides the plain HTTP trigger while still reusing the same curl worker for the forecast fetch.

The default cadence is 10 minutes — weather moves slowly and Open-Meteo updates roughly hourly, so this stays well clear of the free tier's rate limits. Changing the city re-geocodes and fetches within seconds rather than waiting for the next period. While the city is empty the node enters its red configuration-required state and does not poll.

Output

The node has no input; wire its output into a Weather Report sink for a rendered card, or into a Debug, Graph, or Query / JMESPath / JSON Path node. The emitted message carries these data-bag members:

MemberDescription
success Whether a current reading was obtained.
value Current temperature in °C — the canonical value.
temperature Same as value, explicitly named.
humidity Relative humidity, %.
wind_speed Wind speed at 10 m, km/h.
weather_code WMO weather code (integer).
description Human label for the weather code.
city / country The resolved place.
latitude / longitude The resolved coordinates.
output One-line human summary.
raw The provider's full JSON response verbatim, so a downstream node can read any field not promoted to a member above (apparent temperature, day/night flag, cloud cover, pressure, precipitation, wind direction, and so on).
PropertyDescription
city Place name to fetch weather for (e.g. Berlin or Berlin, US). Resolved to coordinates via Open-Meteo's geocoding service before each forecast fetch. Required.
url Open-Meteo forecast endpoint. Defaults to the public service; point it at a self-hosted instance if you run one. The geocoding endpoint is fixed.
period Seconds between fetches (default 600).
