Weather

Group: Network. Type: PnWeather.

Auto-triggered source that polls the current weather for a named place from one of two free, key-less providers (selected with the provider property):

  • Open-Meteo — global coverage; the default.
  • Bright Sky — DWD open data, covering Germany and parts of central Europe only. Outside that area the fetch reports that no station is near the location; switch back to Open-Meteo for worldwide coverage.

It is a specialised Http Client: each tick first resolves the configured city to latitude/longitude through Open-Meteo's geocoding endpoint (which is global and shared by both providers; the result is cached until the city changes), then fetches the forecast for those coordinates. Because that is two requests rather than one, the node overrides the plain HTTP trigger while still reusing the same in-process worker for the forecast fetch.

The default cadence is 10 minutes — weather moves slowly and the providers update roughly hourly, so this stays well clear of either free tier's rate limits. Changing the city or provider re-fetches within seconds rather than waiting for the next period. While the city is empty the node enters its red configuration-required state and does not poll.

Output

The node has no input; wire its output into a Weather Report sink for a rendered card, or into a Debug, Graph, or Query / JMESPath / JSON Path node. The emitted message carries these data-bag members:

MemberDescription
success Whether a current reading was obtained.
value Current temperature in °C — the canonical value.
temperature Same as value, explicitly named.
humidity Relative humidity, %.
wind_speed Wind speed at 10 m, km/h.
weather_code WMO weather code (integer). Open-Meteo only — Bright Sky reports conditions as text, so it omits this.
description Human label for the current conditions.
city / country The resolved place.
latitude / longitude The resolved coordinates.
output One-line human summary.
raw The provider's full JSON response verbatim, so a downstream node can read any field not promoted to a member above (apparent temperature, day/night flag, cloud cover, pressure, precipitation, wind direction, and so on).
PropertyDescription
city Place name to fetch weather for (e.g. Berlin or Berlin, US). Resolved to coordinates via Open-Meteo's geocoding service before each forecast fetch. Required.
provider Forecast source: Open-Meteo (global, default) or Bright Sky (Germany / central Europe). Changing it re-points url at that provider's default endpoint and re-fetches.
url Forecast endpoint for the selected provider. Defaults to the public service; point it at a self-hosted instance if you run one. The geocoding endpoint is fixed.
period Seconds between fetches (default 600).
