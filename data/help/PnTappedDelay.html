Tapped Delay

Group: Filters/Timing. Type: PnTappedDelay.

A time-staggered fan-out. It has one input and a configurable number of outputs. Every arriving message is sent, unchanged, out of each output in turn: output 1 after one step, output 2 after two steps, and so on, where a step is step-ms milliseconds. With a 250 ms step and four outputs:

OutputSends the message after
out 1250 ms
out 2500 ms
out 3750 ms
out 41 s

Each output is labelled with its delay on the worksheet, and shows the value it sent last. Use it for a running-light chase, to start several devices one after another instead of all at once, or for an echo. A single wire straight from the source gives you an undelayed copy as well.

Compare Delay, which forwards each message once after a fixed time, and Shift Register, which shifts by message count rather than by time.

Nothing is dropped or merged: a burst of messages arrives on every output as the same burst, in the same order, shifted later.

PropertyDescription
outputs Number of outputs, 2–16. Default 4. Lowering it drops the copies still waiting for the removed outputs; wires on outputs that no longer exist stop carrying messages.
step-ms Milliseconds between consecutive outputs, 0–3600000 (one hour). Default 250. A change applies to messages that arrive afterwards; copies already waiting keep their original timing. With 0 every output fires on the next pass of the main loop, output 1 first.

Waiting copies are runtime state: they are not saved with the worksheet, and they are discarded when the node is deleted.
