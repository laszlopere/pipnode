Switch

Group: Sources. Type: PnSwitch.

Two-position slide switch. Clicking the slider toggles the latched state and emits a single message whose data.value is 1.0 in the “on” position or 0.0 in the “off” position; data.success mirrors the same state as a boolean so a downstream edge filter can react to the transition directly.

Incoming messages drive the latch like an upstream remote: when the inbound data.value crosses zero (positive → on, zero or negative → off) the switch flips to match and the message is forwarded, so another switch — or any node emitting a 0 / 1 value — can drive this one without manual clicks.

A message whose data.value matches the latch's current position is dropped on the floor: the switch acts as a single stable-state representative, and forwarding the no-op edge would close feedback loops like physical relay → MQTT Source → Tasmota Relay Status → Switch → Tasmota Relay Command → MQTT Sink → physical relay into endless message storms (we turn off the light, which tells us the light is off, which we publish to turn the light off, …). The user can read the current state off the slider and does not need a stream of confirmations to know nothing changed.

Messages without a numeric value cannot drive that cycle and may carry annotations the user expects to flow through, so they pass through unchanged with the latch left alone.

On startup the switch emits its current position once, shortly after the worksheet loads, so downstream nodes know the latch state without waiting for a click. This mirrors how the periodic data sources (and the Knob) report on load, but it is a single shot — the switch never re-emits on a timer. Device-flavoured subclasses whose output is a physical command (the Tasmota Switch, which sends an MQTT relay command) deliberately suppress this so opening a worksheet never actuates hardware.

PropertyDescription
on Current latched position. Writing the property flips the visual state without emitting a message; use the worksheet click (or the public pn_switch_toggle() API) to flip and emit in one step.
