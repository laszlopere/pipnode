Oscilloscope

Group: Sinks. Type: PnOscilloscope.

A display sink styled as an old square-screen, green-phosphor CRT oscilloscope — the kind found on a bench around 1980–1990, moulded bezel, etched graticule and a glowing beam. It traces a Y value against an X value, both read from each incoming message. By default it fits the trace to the screen automatically; lift the card into the zoom overlay and four bench-scope knobs appear to set the scale by hand (see The knobs below).

What makes it the display end of the analog-computer / vector family is that each coordinate may be either a plain number or a $pnvector (a large numeric array carried efficiently in the message):

  • Vector value — the whole vector is the trace for that frame, a captured waveform that replaces whatever was on screen. If the X member is also a vector it supplies the X coordinate per sample (a parametric or Lissajous curve); otherwise each sample is plotted against its index. So feeding just a value vector (no X) draws the waveform left-to-right.
  • Scalar value — only the single current (x, value) point is shown, drawn as a dot. No history is kept: each scalar message replaces the last, so the dot simply moves to the new position. The X member is the matching number, or 0 when no X is supplied (the dot then rides the centre line and moves only vertically with the value). Feed a scalar x and a scalar value together to watch the dot trace out an X-Y position live. The axes auto-fit to the range the dot has explored so far (the frame only widens, never shrinks), giving the dot a stable area to move within rather than pinning it to the centre. The dot itself carries the same blooming phosphor halo as the beam, and as it moves it streaks a fading afterglow: a glowing line is drawn back to the position it just left, then decays over about a second like real CRT persistence.

The two modes never blend: a vector frame clears the scalar point, and the next scalar sample clears the captured waveform.

Both axes auto-range over the visible data, with a small margin, so the curve always fills the screen no matter its amplitude or offset. A dense waveform (potentially millions of samples) is decimated to the screen width for drawing while its true extent still sets the bounds, so the envelope is faithful and the repaint stays cheap. With no signal yet, a dim flat baseline sits across the centre.

The header is the standard card; the CRT screen is painted below it. Clicking the screen lifts it into the centred zoom overlay for a closer look, keeping the screen's aspect ratio.

The knobs

While the card is maximized in the zoom overlay the CRT retreats to the top-left corner and a small control panel appears around it — four rotary knobs in the column to its right and two Auto buttons in the strip below. The knobs are the classic bench-scope controls, two per axis:

  • X range / Y range — the width of the visible window in data units (how much of the signal fits across / up the screen). Drag a range knob up to zoom in (a smaller window), down to zoom out.
  • X offset / Y offset — the data value at the centre of the screen, i.e. the trace's position. Drag an offset knob to pan the trace; one screen-height of drag pans exactly one screenful.

Each knob also responds to the mouse wheel: spin it with the pointer over a knob to nudge that knob up or down without the fiddly drag — one detent stands in for a small slice of drag in the same direction.

Turning any knob switches that axis from auto-fit to a fixed manual window (offset ± range/2); while an axis is still auto-fitting its knobs are dimmed and simply mirror the live auto values, so the first drag grabs smoothly from where the trace already is. To go back to auto-fit, press that axis's Auto button, or double-click any of its knobs. The four values are saved with the document and can also be set directly on the Scale tab of the settings dialog. (x-from-zero / y-from-zero only apply while the axis is in auto mode.)

A worked example

Wire Ramp to produce ramp(0, 2π, 256) on data/value, run it through the Calculator to compute sin(value), and feed that into the oscilloscope. With no X member present, the 256-point sine is drawn against its sample index — one clean cycle, fitted to the screen. To get a true parametric plot instead (Y against a separate X axis), arrange for both a value and an x vector to ride on the same message. Or feed a scalar x and a scalar value (for example a Knob through a Calculator) and watch a single dot move across the screen as the inputs change.

PropertyDescription
value-key Data-bag member holding the Y value (default value). May be a number — parsed from a numeric string too — or a $pnvector. Clearing it disables the node.
x-key Data-bag member holding the X value (default x). May be a number or a $pnvector. Optional: when absent, a vector value is plotted against its sample index and a scalar value's dot sits at X = 0 (centred).
trace-color Colour of the electron beam / waveform. Defaults to a bright phosphor green; the beam is drawn with a soft glow and a near- white core for the blooming-CRT look.
trace-width Stroke width of the beam, in pixels (1–8, default 2). It scales up with the node when lifted into the zoom overlay.
screen-color Backdrop of the CRT screen behind the trace. Defaults to a near-black green; a corner vignette adds a hint of CRT curvature.
grid-color Colour of the graticule divisions etched on the screen.
show-graticule Whether to draw the 10×8 division grid, with brighter centre axes and fine tick marks (default on).
x-from-zero Anchors the X axis at zero instead of auto-fitting it tightly around the data.
y-from-zero Anchors the Y axis at zero instead of auto-fitting it tightly around the data — useful when the absolute magnitude of Y matters and tight auto-fit would exaggerate small wobbles.
x-auto / y-auto Whether that axis auto-fits the data (default on). Turning a knob, or setting a range/offset, switches it off; the Auto button (or a double-click on a knob) switches it back on.
x-range / y-range Width of the visible window along that axis in data units, used when the axis is in manual mode. Setting it switches the axis to manual.
x-offset / y-offset Data value at the centre of the screen along that axis (manual mode). Setting it switches the axis to manual.

In the node's settings dialog these properties are split across three tabs: Appearance collects how the trace is drawn (trace-color, trace-width, screen-color, grid-color, show-graticule); Data collects what is plotted and how the axes are framed (x-key, value-key, x-from-zero, y-from-zero); and Scale holds the manual window controls that the maximized-view knobs drive (x-auto, x-range, x-offset, y-auto, y-range, y-offset).
