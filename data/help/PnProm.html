PROM

Group: Filters. Type: PnProm.

A programmable read-only memory: a lookup table from address to stored word. The arriving data.value is the address. It is rounded to the nearest whole cell — the way a real PROM decodes its address lines — the word programmed at that address replaces data.value, and the message is forwarded. An address that appears nowhere in the image reads back as 0.00, just as an unburnt cell reads 0x00. The decoded address is also written to data.address, so a downstream Debug or Format can show which cell was read. Messages without a numeric data.value drive no address line and are dropped.

The memory image is one <address> <word> pair per line. Either column may be written in hexadecimal (0x…) or decimal, the word may be fractional or negative, blank lines and #-comments are ignored, and a later line for an address reprograms that cell. A line that is not a valid pair puts the node into the error state (painted red with ❗ on the worksheet) while the lines that did parse keep working. 

# address  word
0x0000     0xff
0x0001     0x1a
2          1.5
PropertyDescription
contents The whole memory image, edited in a multiline text box on the dialog's Contents tab. Defaults to the two-cell example above.
