Http Client

Group: Network. Type: PnHttp.

Auto-triggered HTTP GET. Performs a request against the configured URL once per period seconds and emits the response on its output port. The request runs in-process on a worker thread; its socket-I/O timeout is derived from the period so a slow or unreachable server cannot stall ticks.

The message carries data.success (true on a 2xx response with non-empty body), data.output (reply body or error string), and the raw HTTP status. While the URL is empty the node enters its red configuration-required state.

The URL may embed the node variables ${nodeclass}, ${nodename}, and ${hostname}, which are substituted before each request (for example https://${hostname}/metrics). Any other ${...} is left untouched.

PropertyDescription
url Absolute URL to fetch. Required. ${nodeclass} / ${nodename} / ${hostname} are substituted.
period Seconds between requests.
