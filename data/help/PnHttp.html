Http Client

Group: Network. Type: PnHttp.

Auto-triggered HTTP GET. Performs a request against the configured URL once per period seconds and emits the response on its output port. The request spawns curl on a worker thread; --max-time is derived from the period so a slow server cannot stall ticks.

The message carries data.success (true on a 2xx response with non-empty body), data.output (reply body or error string), and the raw HTTP status. While the URL is empty the node enters its red configuration-required state.

PropertyDescription
url Absolute URL to fetch. Required.
period Seconds between requests.
