Ollama

Group: Filters. Type: PnOllama.

Submits the incoming message's data.output string to an Ollama server's POST /api/generate endpoint, awaits the (non-streaming) JSON reply, and emits a new message with data.output replaced by the model's response. All other envelope fields (topic, id, source back-reference, every other member of the data bag) are preserved, so the node slots in next to PnFormat / PnRewrite / any other transformer that reads or writes the same field.

The HTTP call goes through libsoup-3 on the GTK main loop and is fully asynchronous — the worksheet stays responsive while the model is generating, even when the reply takes seconds (long prompts) or minutes (cold-start of a large model). A request never overlaps itself per message: the outgoing emit happens from the async reply callback, after the model has finished.

PropertyDescription
hostname Hostname or IP of the Ollama server. Defaults to localhost. Use the LAN name of a GPU host (e.g. gpu.lan) to offload inference.
port TCP port of the Ollama HTTP API. Defaults to 11434 — the upstream default.
model Ollama model id (e.g. llama3.2:latest, mistral:7b). The settings dialog populates this from the server's GET /api/tags listing; a refresh button next to the combo re-queries on demand (the list also re-queries automatically when hostname or port changes). Whatever value is currently saved stays selectable even when the server is unreachable.
keep-alive How long Ollama keeps the model resident in memory between requests. Forwarded verbatim to the API's keep_alive field. Accepts:
  • a duration like 5m (the default), 30s, 1h — the "session" window the user asked about: the model stays warm for that long after the last call;
  • 0 — unload the model immediately after each request (cold start every time, lowest idle memory);
  • -1 — keep the model resident forever (fastest repeat calls, never reclaims VRAM on its own).
prefix Text prepended to the incoming data.output before the combined string is sent. The place to put system / role framing (e.g. "Translate the following to French:\n\n").
suffix Text appended after the incoming data.output. Useful for trailing instructions like "\n\nRespond in one sentence."

The node renders red with a ❗ icon when either hostname is empty or model is unset, so a half-configured node is visually obvious at a glance. A failed HTTP call (host unreachable, HTTP ≥ 400, malformed JSON, {"error": ...} body) logs a warning to stderr and drops the message — no emit happens, so downstream nodes do not see a half-formed response.

This node depends on a reachable Ollama server speaking the standard HTTP API at http://<hostname>:<port>/api/{tags,generate}. Install Ollama from ollama.com, pull a model (ollama pull llama3.2), and the running daemon will answer on port 11434 by default.
