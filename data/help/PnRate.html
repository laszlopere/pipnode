Rate

Group: Filters. Type: PnRate (subclass of PnHttp).

Crypto/fiat exchange-rate converter. For every received message the node multiplies data.value by its cached conversion factor (from → to) and forwards the message with the converted amount, the factor itself in data.rate and the destination currency code in data.currency. Non-numeric or missing data.value fields are left untouched so the message still passes through.

The rate is fetched periodically by the inherited auto-trigger, defaults to CoinGecko's simple/price endpoint, and pivots through USD so a single request covers any pair the node supports. The fetched rate and the timestamp of the last successful fetch round-trip through the worksheet on save/load — so re- opening a flow does not fire a fresh request and the previously-saved rate is used until the next periodic tick, keeping repeated workspace reopens out of the upstream provider's rate-limit log.

PropertyDescription
url Endpoint base URL. The node appends ?ids=…&vs_currencies=usd at request time. Defaults to CoinGecko's free simple/price.
from Source currency. Pick from a 23-entry alphabetical list: ADA, ATOM, AVAX, BCH, BNB, BTC, CRO, DOGE, DOT, ETH, LINK, LTC, MATIC, PLS (Pulse Chain), SOL, TRX, UNI, USD (the pivot used to quote every pair), USDC, USDT, XLM, XMR, and XRP. The settings dialog renders each entry next to its bundled icon so the picker reads at a glance.
to Destination currency. Same set as from; when from equals to the node is marked as needing configuration and skips its fetches.
rate Cached conversion factor (1 unit of from equals rate units of to). Defaults to 1 and is overwritten on every successful fetch; persisted with the worksheet.
last-update ISO-8601 timestamp of the last successful fetch. Persisted with the worksheet alongside rate.
period Seconds between rate refreshes. Floor is 600 (10 minutes); attempts to set a smaller value — from the dialog or by hand-editing a saved worksheet — are silently rounded back up.

Wire one in after any node that emits a numeric data.value with from = ETH, to = USD to convert that value into dollars before it reaches a Debug or Graph sink.
