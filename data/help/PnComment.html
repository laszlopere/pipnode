Comment

Group: Annotation. Type: PnComment.

A free-text annotation box you drop on the worksheet to document a flow — a white, resizable rectangle with a grey frame holding a few paragraphs of wrapped text. It is not part of the message graph: a comment has no input or output ports, never receives or forwards a message, and never fires. It exists purely to label and explain the worksheet around it.

Add one by right-clicking an empty spot on the canvas and choosing Add note (the box appears under the cursor), or by dragging the Comment entry from the node palette. Like any node it can be selected, moved, copied, pasted and deleted, lives on a single sheet, and is saved with the document (so it round-trips through save / load and undo / redo).

Resizing. Select a comment and drag one of the eight square handles on its edges and corners; the box grows or shrinks and the text re-wraps to fit. The frame keeps a small minimum size so it can never collapse to nothing.

Editing. Double-click the box (or right-click → Configure) to open its dialog. The Text tab holds the multi-line text editor and the font size; the Colours tab lets you recolour the fill, the frame and the text. Text that overflows the box is cropped rather than spilling out — make the box bigger or the font smaller to reveal it.

PropertyDescription
text The comment body. May contain several paragraphs; the text wraps to the box width.
text-size Font size of the text, in pixels.
background-color Fill colour of the box — white by default. Set its alpha to zero for a frame-only, transparent note.
frame-color Colour of the box outline — grey by default.
text-color Colour of the text — a dark slate by default.
width, height The box footprint in pixels. Normally set by dragging the resize handles rather than typed in.
