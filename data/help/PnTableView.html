Table View

Group: Sinks. Type: PnTableView.

Sink that renders the latest structured table carried on data.table of an incoming message. Designed to live downstream of a Table Model filter, so a wiring like Shell Command → Table Model → Table View shows the most recent run of e.g. df -h as a live, column-aligned table view on the canvas.

The expected payload shape is the one Table Model produces: 

{
  "header": { "cells": [ { "text": "..." }, ... ] },          // optional
  "rows":   [ { "cells": [ { "text": "..." }, ... ] }, ... ]
}

Each cell is a JSON object; the view renders the cell's text member and ignores anything else, leaving room for future per-cell decorations (colour, alignment, ...) to ride alongside without breaking the renderer. A hand-built payload that puts a bare string, number, or boolean where a cell object is expected is stringified directly so a producer that has not been updated to the object form still draws something sensible.

Each received message replaces the displayed table (unlike Table, which appends one row per message). A message that carries no data.table object clears the view to its empty "waiting for table" state — useful for spotting that the upstream producer has stopped emitting parsable tables rather than being left with a stale render.

Visually the node matches Table exactly (280 px wide header, 173 px body) so a row of mixed table sinks lines up on the worksheet. Clicking the body lifts the table into the shared zoom overlay where the mouse wheel scrolls through rows.

background-color Fill behind the rows.
