Stats

Group: Filters. Type: PnStats.

Counts incoming messages and tracks the time between consecutive arrivals over a rolling window. The original message is consumed; for every receive the node emits a brand-new message with topic stats whose data bag carries the tallies aggregated across the last window seconds. Internally the window is split into bins equal-sized buckets, each storing only summary tallies — individual messages and timestamps are never retained, so memory is O(bins) regardless of arrival rate or payload size. The window slides one bin at a time rather than one message at a time.

PropertyDescription
window Length of the rolling window in seconds. Defaults to 60, range 1–86400.
bins Number of buckets the window is split into. Defaults to 60, range 1–3600. Higher values trade memory for a finer slide step.
FieldDescription
data.count Messages observed within the rolling window.
data.min_seconds Smallest inter-arrival gap whose ending arrival landed in the window, in seconds.
data.max_seconds Largest such gap, in seconds. Includes gaps that exceed the window itself when the next arrival eventually lands.
data.average_seconds Mean of the inter-arrival gaps in the window.
data.per_minute Throughput as messages per minute, computed as count / window. Reads as a "messages in the last N seconds" curve when graphed.
data.per_hour Throughput as messages per hour.
data.per_day Throughput as messages per day.
