File Viewer

Group: Sinks. Type: PnFileViewer.

Display sink that shows whatever arrives on its input. It paints a view rectangle below its header (the same way the Graph node paints its plot area, and the File Drop source paints its drop area) and draws the incoming picture inside it.

When the incoming message is a PnImageMessage — the specialised message the File Drop source emits, which carries the decoded image by pointer — the node takes a reference on that same image and resizes its view area to the image's own aspect ratio (at a fixed width, clamped to sane bounds), so the picture fills the rectangle edge-to-edge with no white margin. The render is identical to the one the File Drop produces, so wiring a File Drop's output to a File Viewer's input shows the very same image twice, both straight from the message — no file is re-read and the pixels are never copied, just ref-shared.

Any other message clears the preview and falls back to a hint — the file name from the message's data.filename when present, otherwise “Nothing to show”.

Message data members

The viewer only reads input; it emits nothing. It looks at one optional member of the incoming message:

MemberDescription
data.filename Base name shown as the hint when no image is on display (e.g. after a non-image message). Optional.
Properties
PropertyDescription
area-color Fill colour of the view-area rectangle (white by default, shown only while the area is empty).
border-color Colour of the 1 px frame around the view area.
