Delay

Group: Filters. Type: PnDelay.

Time shifter. Forwards every message it receives unchanged, but only after delay-ms milliseconds have elapsed. Each message is held independently on its own one-shot timer, so a burst arrives downstream as the same burst shifted later in time — nothing is dropped or coalesced and the original order is preserved. This is the opposite of Throttle, which thins a stream rather than delaying it.

A delay of 0 still defers each message to the next main-loop iteration rather than forwarding it inline. Messages still waiting on their timers when the node is deleted (or the worksheet closed) are discarded without being forwarded.

PropertyDescription
delay-ms Milliseconds to hold each message before forwarding it.
