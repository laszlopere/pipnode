XY Graph

Group: Sinks. Type: PnXYGraph.

Sink that scatter-plots a pair of numbers plucked from each incoming message. Unlike the Graph node — which plots one value against its arrival time — the XY Graph reads both coordinates from the message: the Y value from the key path (default data/value) and the X value from the x-key path (default data/x). A message that is missing either coordinate, or whose coordinate is non-numeric, plots no point. The header is rendered at twice the canonical width; below it (with a small gap) a plot rectangle shows the points, with both axes auto-ranging over the visible data. Plotting is done with PLplot.

Each node keeps a ring of the most recent max-points samples per topic; older samples scroll off the end. Because the X axis is an explicit value rather than a clock, there is no time window or resolution to configure — the plot simply shows the last N points it has seen.

Multiple series

Every distinct msg.topic on the input wire is tracked as a separate series with its own ring. All series are overlaid on the same 2D axes, each drawn in its own colour: series colours are derived from line-color by walking the HLS hue wheel in golden-angle steps so adjacent series read distinctly without the user having to pick a palette. The first series keeps the line-color exactly, so single-topic worksheets look unchanged. Up to 12 distinct topics are tracked; messages introducing a 13th topic are dropped silently so a pathological feed that synthesises a new topic per message cannot grow memory without bound.

PropertyDescription
x-key JSON path (“/”-separated, e.g. data/x) to the value plotted on the X axis. Resolves against the same root used by Format's placeholders. Numbers are accepted directly; strings are parsed too — either as base-10 (with optional sign and fractional part) or as a hex literal with a 0x/0X prefix. Missing, unparsable, or non-finite values drop the whole sample.
key JSON path to the value plotted on the Y axis (default data/value). Parsed and coerced exactly like x-key. Both an X and a Y value must resolve for a point to be plotted.
max-points How many of the most recent (x, y) samples to keep and plot per series (2–2048, default 2048). Older samples scroll off the end of the ring. Lowering it focuses the plot on the latest data; raising it shows a longer trail.
draw-style How each series is drawn (the “Draw as” setting): Points (default) marks each sample with a filled circle — the natural scatter form — while Lines connects the samples, in arrival order, with a polyline, which reads as a trajectory. A series with a single sample is always drawn as a point even in Lines mode (there is no segment to draw).
line-color Colour of the first series. Defaults to a dark blue that reads well against a white background. When more than one topic is present, subsequent series walk the hue wheel in golden-angle steps from this base.
line-width Stroke width of the polyline in Lines mode, or the marker size scale in Points mode, in pixels (1–8, default 2).
axis-color Colour of the plot frame, ticks, and tick labels. The same colour is used for the thin frame painted around the plot rectangle.
background-color Fill colour of the plot rectangle behind the data. Defaults to white.
show-grid When enabled, draws a thin grid through every major tick on both axes for easier reading of values.
x-from-zero Anchors the X axis at zero instead of auto-fitting it tightly around the data. A series whose X values already straddle zero is unaffected.
y-from-zero Anchors the Y axis at zero instead of auto-fitting it tightly around the data — useful when the absolute magnitude of Y matters and tight auto-fit would exaggerate small wobbles.

In the node's settings dialog these properties are split across two tabs: Appearance collects how the plot is drawn (draw-style, line-color, line-width, axis-color, background-color, show-grid), while Data collects what is plotted and how the axes are framed (x-key, key, max-points, x-from-zero, y-from-zero).
