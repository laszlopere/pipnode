Analog Meter

Group: Sinks. Type: PnAnalogMeter.

A flat panel-meter sink — a square white plastic case with a moulded bezel, an inset paper-white face, a diagonal arc of black tick marks with engraved digits running from the lower-left corner up through the top of the face to the upper-right corner, a long thin black needle whose pivot bearing sits in the lower-right corner (a small dark disc with a single light slot across the head, which is the moving-coil pivot the needle swings around) and an accuracy- class digit at the lower-left — the classic AC voltmeter / ammeter look you find on every old electrical panel. It reads the latest numeric value plucked from every incoming message via a JSON path (key) the same way the Dial sink does, and animates the needle to its new position through the same damped-spring integrator so a step input swings the needle past the target and settles back on it the way a real moving-coil meter does. When the key cannot be resolved or the resolved value is not finite the needle stays where it was; out-of-range readings clamp to the nearest scale endpoint instead of swinging past the ticks.

The case is square (220 × 220 px) and sits below the standard Node-RED-style header. Clicking the face lifts the meter into the centred zoom overlay the same way it does for the Dial and the other large sinks, so a worksheet that wires several meters in a row can zoom into one for a closer reading without rearranging the canvas.

Choosing between the Analog Meter and the Dial

Both sinks read a single numeric value off the message and drive a needle. Use the Analog Meter when you want the look of an old panel-mount meter -- a square plastic housing, a diagonal arc scale that fills the upper-left triangle of the face with the pivot in the lower-right corner, and a stark monochrome readout appropriate for a meter that names its quantity by the unit glyph in the empty upper-left corner rather than by a colour-coded zone band. Use the Dial when you want a round bezelled gauge with optional green / yellow / red warning zones, a metallic centre pivot and a glassy face reflection -- the look of a process-control dashboard rather than an electrician's lab bench.

Scale geometry

The scale runs from min-value to max-value along an arc. Angles are measured in degrees, clockwise from 12 o'clock; the pivot lives at the lower-right corner of the face, so the default start-angle = -90 / end-angle = 0 sweeps a 90° diagonal arc -- the low end of the scale sits at the lower-left corner of the face (the needle pointing horizontally to the left) and the high end at the upper-right corner (the needle pointing straight up). The arc radius is sized automatically from the actual sweep, so a narrower or wider sweep grows / shrinks the radius to fit the case without needing the user to adjust any other property.

Major tick marks are placed at “nice” value positions ({1, 2, 5} × 10n apart, the same heuristic matplotlib and gnuplot use for axis labels) derived from the major-ticks property, which acts as an upper bound on the tick count rather than as a hard count. Minor tick marks subdivide each major-tick segment evenly; the default 10 minor-ticks-per-major matches the typical electrical meter where every 10 V (or 10 mA) gets its own short tick between the labelled 100 V boundaries.

Cosmetic text

The unit property is the dominant glyph printed in the upper-left corner of the face -- opposite the pivot, which is the only generously-sized empty region on a diagonal-scale meter -- typically a single letter (“V”, “A”, “mA”) so it reads as the unit the meter measures at a single glance. When ac-mode is TRUE (the default) a small sine-wave “~” glyph is painted above the unit, the international symbol for an AC-only instrument; flip it to FALSE for the look of a DC meter. The accuracy-class property is a small string printed at the lower-left corner of the face (typically the IEC accuracy class -- “2.5”, “1.5”, “0.5”); cosmetic only, the value does not affect any readings.

Properties
Data
  • key — JSON path (“/”-separated, e.g. data/value) to the numeric value the needle points at. Default data/value.
  • unit — Dominant unit glyph drawn at the top centre of the face. Default V.
  • mode — picks which IEC current-type symbol is painted directly below the unit. AC paints the sine wave “~” (IEC 60417-5032); DC paints a solid line above three short dashes (IEC 60417-5031); None leaves the slot empty, for meters whose unit ("Hz", "°C") has no AC/DC sense. Default AC.
  • accuracy-class — Small string at the lower-left corner of the face. Default 2.5.
Scale
  • min-value / max-value — numeric range of the scale. Defaults 0 / 300.
  • start-angle / end-angle — angles (degrees, clockwise from 12 o'clock) of the needle at the scale endpoints. Defaults -90 / 0 (the diagonal lower-left → upper-right sweep around the lower-right pivot).
  • major-ticks — upper bound on the number of major tick marks. Default 4 (so the default 0 .. 300 range gets ticks at 0, 100, 200, 300).
  • minor-ticks-per-major — subdivisions between two consecutive major ticks. Default 10.
Colours
  • face-color — fill colour of the inset dial face. Default near-white.
  • scale-color — colour of the tick marks, the scale arc and the digit labels. Default near-black.
  • needle-color — fill colour of the needle. Default near-black.
  • label-color — colour of the unit glyph, the AC “~” wave and the accuracy-class string. Default near-black.
Message contract

See the Messages section of the help index for the full message envelope and the standard data-bag members. This sink ignores everything except the value at key, which it coerces to a finite double (int, double and numeric-string JSON values are all accepted).
