Debug Print

Group: Sinks. Type: PnDebug.

Sink that prints every received message to a chosen destination in a chosen format. Indispensable for inspecting a flow.

PropertyDescription
target Where output goes: stderr, stdout, status bar (the main window's footer) or debug view (the collapsible pane toggled from View → Debug View).
format How each message is rendered: text (just data.output), oneliner (a compact human trace including topic, id and payload), or JSON (one JSON object per line wrapping source/topic/id/data — friendly for piping through jq).
