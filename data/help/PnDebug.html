Debug Print

Group: Sinks. Type: PnDebug.

Sink that prints every received message to a chosen destination in a chosen format. Indispensable for inspecting a flow.

PropertyDescription
target Where output goes: Debug View (the collapsible pane toggled from View → Debug View), Status Bar (the main window's footer), Standard Output or Standard Error.
format How each message is rendered: text (just data.output), oneliner (a compact human trace including topic, id and payload), or JSON (one JSON object per line wrapping source/topic/id/data — friendly for piping through jq).
Large numeric vectors

When a message carries a big out-of-band numeric vector (a $pnvector member, as emitted by the signal-generator and Calculator nodes), the oneliner and JSON formats do not dump every value. The vector is previewed as a short, bounded leading sample with its total count — for example [0, 1, 2, 3, 4, 5, 6, 7, …] (256 values) — so even a megabyte vector renders as one tiny string and never freezes the Debug View. This is the same preview the Calculator writes to its output field.
