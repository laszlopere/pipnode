Segment16

Group: Sinks. Type: PnSegment16.

Paints an incoming string on a row of sixteen-segment LED cells — the alphanumeric cousin of the Countdown readout. The classic starburst font lights the right combination of orthogonal bars, middle bars and four inner diagonals to render digits, letters and a small set of punctuation. Lower-case letters fall back to the upper-case shape so the display reads as a uniform LED panel.

Each incoming message must carry a string output — same convention as the Label node. The text is laid out left to right and cropped to the configured cell count; a message with no string output, or with empty output, blanks the row. Anything outside the printable ASCII range, or a punctuation mark with no glyph in the font, lights no segments in its cell.

Being a sink, the node never forwards a message. The display repaints only when the visible text actually changes, so a hot source does not drive a redraw faster than the readout content moves.

SettingDescription
cells Number of 16-segment character cells in the row (1–32). Eight (the default) is about as wide as a panel clock; raise it for longer readouts. Text longer than the row is cropped on the right.
background-color Fill colour of the panel face behind the cells — the near-black face of an LED clock by default.
segment-color Colour of a lit segment bar — the classic LED red by default.
unlit-segment-color Colour of an unlit segment bar — the dark off-state ghost of a cell, a dim red over the black face by default.
