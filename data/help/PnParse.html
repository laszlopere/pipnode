Parse JSON

Group: Filters. Type: PnParse.

Turns a JSON string held in one member of the message into real structure, so the rest of the pipeline can address it. The Http Client hands its response body back as an opaque string in data.output; a JMESPath expression runs against the message tree, where that body is still one long string and none of its fields are reachable. This node is the bridge between the two.

A message is never dropped, and a failure is never destructive: when the text cannot be parsed the data bag is forwarded exactly as it arrived — the unparsed body is still there to look at — with the reason added as data.error. The node also lights its error lamp on the worksheet, and clears it again on the next message that parses.

PropertyDescription
source-field Slash-separated path to the string that should be parsed. The default data/output is where Http Client leaves a response body. It is an error for the path to be missing or to address something that is not a string.
result-field Where to put the parsed document. A non-empty name (default result) writes to that member of the data bag, leaving the surrounding members — including the raw body — in place. The empty string or the literal data mean the document is the new data bag: existing members are dropped, and a non-object document (a bare number, string, or array) is wrapped under a value key so the bag stays a well-formed object.
Typical wiring

Fetch a REST endpoint and read one field out of the response: 

Http Client  →  Parse JSON  →  JMESPath  →  Numeric
             body      result       result.sensor.temp

With result-field left at result, the JMESPath node should use source-field = data and an expression like result.sensor.temp. Setting result-field to the empty string instead makes the response body become the data bag, so the same expression shortens to sensor.temp — at the cost of discarding data.status, data.url, and the raw body along with it.

Errors
data.errorCause
source-field is empty No path configured.
no such field The path does not resolve in the incoming message.
field is not a string The path resolves to a number, object, array, or null. Already structured data needs no parsing.
empty document The string held nothing but whitespace.
(parser message) The text is not valid JSON; the message comes from the JSON parser and names the offending line.
