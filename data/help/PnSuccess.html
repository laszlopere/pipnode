Success

Group: Filters. Type: PnSuccess.

Pass-through filter that forwards a message only when its mandatory data.success boolean is true. Messages whose success member is missing or not a boolean are dropped.

Use this rather than a generic Filter with a one-rule predicate on the contract field when a flow needs to branch on the success bit alone — e.g. routing successful HTTP responses to one sink and failed ones to another, or muting an alert while everything is green. The dedicated counterpart is Failure, which forwards the opposite messages by the same rule. Edge is the related node that forwards only the transitions in data.success (one message per state change), rather than every successful one.
