Format

Group: Filters. Type: PnFormat.

Rewrites data.output from one of two templates, selected by data.success. Each template may embed ${path/to/field} placeholders that resolve against the incoming message JSON: the root carries topic, id, and data (the payload bag), so for example ${data/value} resolves to the data bag's value member.

PropertyDescription
success-text Template used when data.success is true.
failure-text Template used when data.success is false or missing.
success-text: "${topic} OK — ${data/output}"
failure-text: "${topic} DOWN at ${data/host}"
