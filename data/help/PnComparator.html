Comparator

Group: Filters. Type: PnComparator.

Two-input ordering comparator — the live-reference sibling of Threshold. Where Threshold compares the incoming value against a fixed number, Comparator compares two streams: input 1 (A) and input 2 (B) each carry a numeric value. The node latches the most recent value seen on each input and tracks a single on/off state answering “is A at or above B?”. It forwards a message only when that state changes, rewriting value to 1.0 (A ≥ B) or 0.0 (A < B) — the same 0.0/1.0 encoding the rest of Pipnode uses for on/off.

hysteresis defines a dead-band centered on equality (A == B). The state turns on once A reaches the upper edge, B + hysteresis/2, and turns off again only once A falls below the lower edge, B − hysteresis/2. While A sits inside that band the state is held, so two values hovering around each other do not flap the output. With hysteresis left at 0 the band collapses onto equality and the node is a plain “A ≥ B” comparator that emits on every crossing.

No comparison happens until both inputs have carried at least one numeric value; the message that completes the pair establishes the initial state (on if A ≥ B, off otherwise) and is always forwarded. A message without a numeric value is ignored and leaves the latched values and state untouched.

PropertyDescription
hysteresis Width of the dead-band centered on equality: A must rise half this above B to turn the output on and fall half below B to turn it off. Zero disables hysteresis.
