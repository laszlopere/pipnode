Value

Group: Filters. Type: PnValue.

Overwrites data.value with a fixed number, regardless of what arrived. Use it to inject a constant numeric payload into a flow — a setpoint, a threshold, a literal reading. The rest of the message (its topic, id, and any other data members) passes through untouched, and the message is always forwarded.

PropertyDescription
value The fixed double written to data.value on every message. Set it with the spin button in the node's settings dialog.
