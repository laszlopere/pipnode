Counter

Group: CPU. Type: PnCounter.

A self-advancing value register — the program counter of a toy-CPU worksheet. It holds one number and has three inputs:

InputEffect
tick (0) Emit the current value on data.value, then advance it by step (wrapping at modulo when that is non-zero). Drive this from a Clock or Injector.
load (1) Store the arriving data.value — a JUMP target. Emits nothing.
reset (2) Store initial. Emits nothing.

A load that arrives while a tick's downstream chain is still running — a jump decoded from the very instruction the tick just fetched — wins over that cycle's implicit advance, so the jump target is what the next tick emits. Because the load and reset ports are silent (like Register), the counter can sit in the fetch/execute feedback loop without forming a synchronous cycle.

PropertyDescription
initial Value the counter starts at and the reset input restores. Default 0.
step Amount added after each tick. Default 1.
modulo When greater than zero, the advanced value wraps into [0, modulo); 0 disables wrapping. An explicit load or reset target is stored unchanged. Default 0.
