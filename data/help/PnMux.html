Mux

Group: CPU. Type: PnMux.

A value-selected multiplexer — the bus / operand-source selector of a toy-CPU worksheet. It has one select input followed by inputs data lines (in1…inN, 2–8 of them). The core latches each line's last data.value, and the node forwards the value of the currently selected line on data.value.

InputEffect
select (0) Latch the selector k — 0 chooses in1, 1 chooses in2, … clamped into range. Emits the newly selected line's value.
in1…inN Data lines. An update on the selected line is forwarded; an update on any other line is latched silently.

So a message leaves the node whenever the selector changes or the selected data line updates. The selector defaults to 0 (in1) until the select line has carried a number.

PropertyDescription
inputs How many data inputs the multiplexer has, 2–8, set with a spin button on the Inputs tab. The node always has one extra leading select input on top of these. Default 2.
