Table

Group: Sinks. Type: PnTable.

Sink that displays the most recent messages it receives as a scrolling table of rows, with a header row that names the columns. Visually it mirrors Graph: a 280 px standard header sits on top, and a separately-painted body of the same width and height shows the data, so a row of mixed Graph and Table sinks lines up cleanly on the worksheet. Rows appear newest-first; older rows fall off the bottom once the buffer reaches the configured limit. Clicking the body lifts the table into a centred zoom overlay (the same animation the graph node uses); while zoomed, the mouse wheel scrolls through the rows.

Columns are configured as a single comma-separated string of “Title:path” entries — one entry per column. The path is the same “/”-separated JSON pointer used elsewhere in the project (it resolves against the same root as Format's placeholders, Graph's key, and Stats's key). An entry without a “:” is treated as path-only with the path doubling as the title, so data/value works as a one-column shorthand. Example: Status:data/status,URL:data/url,ms:data/ms shows three columns of HTTP responses.

Cells are stringified by JSON type: numbers via %g/%"PRId64", booleans as true/false, strings verbatim, missing fields as “—”. Sub-objects and arrays render as the compact placeholders {…} and […] so a row that accidentally points at a nested structure doesn't blow out the column with a multi-line dump — drill in with a deeper path to see the contents flattened. Cell text that doesn't fit its column is truncated with a trailing ….

PropertyDescription
columns Comma-separated Title:path list. Each entry becomes one column; empty entries are skipped, and whitespace around titles and paths is stripped. An entry without a “:” uses its path as the title.
limit Maximum number of rows kept in the buffer (1–1000, default 200). Older rows are dropped from the bottom as new ones arrive. Lowering this trims the buffer immediately.
background-color Fill colour of the body rectangle behind the rows. Defaults to white.
header-background-color Fill colour of the header band. The same colour at 30 % alpha is used as the alternating-row stripe when that option is enabled.
grid-color Colour of the frame, the column separators, and the line that underlines the header.
text-color Colour of the body cell text.
header-text-color Colour of the bold column titles in the header band.
alternate-row-background When enabled (default), tints every second body row with the header background colour at 30 % alpha to make dense feeds easier to read.
