Pipe Writer

Group: Sinks. Type: PnPipeWriter.

Sink that writes every received message into a named pipe (FIFO) as one line, for another program to read. Pair it with the Pipe Reader to pass messages between two pipnode processes, or read it from a shell: 

cat /tmp/pipnode.out

The pipe is created as soon as the path is set, so a reader can open it before the first message is sent. A path that exists but is not a named pipe is refused (the file is left alone). Until a usable path is set the node shows the error state, painted red on the worksheet.

PropertyDescription
pipe-path Path of the named pipe to write. Created when missing. A leading ~ stands for your home directory.
format Output text (the default) writes the message's data.output (an empty line when it has none). JSON message writes the whole message envelope as one compact JSON line, which a Pipe Reader in JSON mode turns back into the same message.
Never blocks

Writing never makes pipnode wait for the other end:

  • While no program has the pipe open for reading, messages are dropped. This is normal and does not turn the node red. The next message tries again, so a reader that starts later receives everything sent from then on.
  • When a reader is connected but reads slowly, unsent lines wait in memory (up to 1 MiB) and are written as the reader catches up. When that is full, new messages are dropped whole — a reader never sees half a line.
  • When the reader goes away, the waiting lines are discarded.

A text message containing newlines arrives at the reader as several lines; use JSON message to keep such text in one piece.
