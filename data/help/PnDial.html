Dial

Group: Sinks. Type: PnDial.

A round analogue dial — metallic bezel, glassy face, thin tick marks with engraved digits, a 3D-shaded needle on a metallic centre pivot, and an optional green / yellow / red zone arc — that reads the latest numeric value plucked from every incoming message via a JSON path (key) the same way the Graph sink does. When the key cannot be resolved or the resolved value is not finite the needle stays where it was; out-of-range readings clamp to the nearest scale endpoint instead of swinging past the ticks.

The dial face is square (220 × 220 px) and sits below the standard Node-RED-style header. Clicking the face lifts the dial into the centred zoom overlay the same way it does for the graph and table sinks, so a worksheet that wires several dials in a row can zoom into one for a closer reading without rearranging the canvas.

Scale geometry

The scale runs from min-value to max-value along an arc. Angles are measured in degrees, clockwise from 12 o'clock, so start-angle = -120 / end-angle = +120 puts the low end at 7 o'clock, the high end at 5 o'clock, and leaves the bottom wedge clear for the configurable label. A 360° sweep is allowed (set start-angle to -180 and end-angle to +180) for clock-face-style indicators.

Major tick marks are placed at “nice” value positions ({1, 2, 5} × 10n apart, the same heuristic matplotlib / gnuplot use for axis labels) derived from the major-ticks property, which acts as an upper bound on the tick count rather than as a hard count. Worked example: a 0-16 scale with major-ticks = 13 picks a step of 2 (raw 1.333 rounded up to the next nice number) and draws ticks at 0, 2, 4, …, 16 — nine ticks, all at clean integer positions. A 0-120 scale with the same target picks step 10 and hits the target exactly (0, 10, …, 120). Between every pair of consecutive major ticks the painter inserts minor-ticks-per-major - 1 minor ticks; set the property to 1 to suppress them. Each major tick carries a digit label rendered in the configurable scale-color — integer when the step is an integer (the common case), one or two decimals otherwise.

The nice-step choice is what makes zone bounds intuitive: a zone entered as “9 to 11” on the 0-16 scale above lands at the exact angles of value 9 and value 11, halfway between the visible “8” / “10” and “10” / “12” tick pairs — rather than at the fractional positions an evenly- subdivided 13-tick arc would have placed values 9 and 11 at.

Zone arcs

Three coloured arcs (green / yellow / red, the traditional gauge palette) sit just inside the tick band. Each one is bounded by {color}-start and {color}-end properties in value units; when the start is greater than or equal to the end the arc is treated as empty and is not drawn, so a worksheet that needs only one zone can leave the other two unset (defaults to a "0…60 green, 60…90 yellow, 90…120 red" split that matches the default 0…120 scale). The arc colours themselves are configurable for users who want to swap the palette — e.g. a "safe" deep green / amber / crimson on a dark face.

Painted vs metallic colours

The metallic-looking parts of the dial — the outer bezel and the centre pivot — are not configurable. They use fixed silver / grey gradients tuned to read as polished steel against any face colour the user picks. Every painted colour (face, tick marks, digits, needle, label, the three zone arcs) is exposed as a GdkRGBA property so the dial can be themed to match the rest of the worksheet.

PropertyDescription
key JSON path ("/"-separated) to the numeric value the needle reads from every incoming message. Default data/value.
min-value / max-value Values at the low and high ends of the scale.
start-angle / end-angle Angles (degrees, clockwise from 12 o'clock) at which the low and high ends of the scale sit. Defaults -120 / +120 give the classic 240° gauge sweep.
major-ticks Number of major tick marks (including both endpoints). Each carries a digit label.
minor-ticks-per-major Number of subdivisions between consecutive major ticks; set to 1 to suppress minor ticks.
label Descriptive line drawn at the lower centre of the face (in the wedge below the centre pivot) in a medium font. Typically the name of the quantity (“speed”, “tank A”). Empty to suppress.
unit Short suffix drawn below label in a much bigger font. Typically one or two characters (“L”, “°C”) so it reads as the dominant identifier for the value on a single-glance read. Empty to suppress.
green-start, green-end, yellow-start, yellow-end, red-start, red-end Value-unit bounds of the three optional zone arcs. An arc is omitted when its start ≥ its end.
face-color Base fill of the dial face. The centre is automatically brightened slightly so the glass highlight has something to sit on.
scale-color Colour of the tick marks and digit labels.
needle-color Fill of the needle body. A black shadow pass and a white highlight stroke (both fixed) give the needle its 3D read.
label-color Colour of the lower-centre label text.
green-color, yellow-color, red-color Stroke colours of the three zone arcs.
