Staircase

Group: Filters. Type: PnStaircase.

Monostable timer, named after the stairwell light switch you press once and that turns itself off a while later. A trigger — any message whose data.value is greater than 0.5 — is forwarded unchanged, after which the node arms a single one-shot timer and goes quiet. When on-time-ms milliseconds have elapsed it emits a fresh message carrying data.value = 0.0 as the turn-off signal and returns to its resting state.

Messages that are not triggers — data.value at or below 0.5, or no numeric data.value at all — are dropped. The node owns the off edge: nothing external disturbs the timed window, so the turn-off you see downstream is always the one this node scheduled.

What happens to a trigger that arrives while the node is already on depends on retriggerable. When it is on (the default), each fresh trigger restarts the timer and pushes the turn-off further into the future — the stairwell light you keep tapping to stay lit. When it is off, in-window triggers are ignored and the original turn-off time stands. Either way a re-trigger is never re-forwarded, because whatever is downstream is already on.

The turn-off message reuses the topic of the trigger that started the window, so a downstream consumer that filters by topic sees the on and off edges as a matched pair. Changing on-time-ms while a window is counting down does not move that window's deadline; the new value governs the next trigger. A timer still counting down when the node is deleted (or the worksheet closed) is cancelled without emitting the turn-off.

PropertyDescription
on-time-ms Milliseconds the node stays on after a trigger before it emits the value = 0.0 turn-off message.
retriggerable When on, a trigger that arrives during the window restarts the timer (delaying the turn-off) instead of being ignored.
