Panel Display

Group: Sinks. Type: PnPanelDisplay.

Surfaces a worksheet value on an XFCE panel applet. It is one half of the panel I/O contract (see Panel Input): a worksheet runs in the background engine — pipnode-editor started as a D-Bus service — and the panel button reflects whatever this node last received.

On each incoming message the node derives a short display string and, if it differs from the current one, stores it and notifies the engine, which pushes it to the applet button. The string is chosen from the standard data-bag members in this order:

  • the data.text string member, if present;
  • otherwise data.value formatted — a boolean as on/off, integers and reals locale-independently;
  • otherwise the message topic, then the empty string.

The node has no output port: it is a terminal display. An empty string hides the applet label, so a display that has not received anything yet leaves the button showing just the pipnode icon.

A worksheet needs no Panel Display to be useful, but a panel applet that should show a value must contain exactly one for the engine to mirror.
