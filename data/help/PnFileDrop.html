File Drop

Group: Sources. Type: PnFileDrop.

Desktop drop target. The node paints a white drop-area rectangle below its header (the same way the Graph node paints its plot area). Drag a file onto that rectangle from your desktop or file manager and the node emits one message describing the dropped file.

When the dropped file is an image, the node decodes it once and resizes its drop area to the image's own aspect ratio (at a fixed width, clamped to sane bounds), so the picture fills the rectangle edge-to-edge with no white margin — just the frame and the drop shadow around it. It then emits a specialised PnImageMessage — a subclass of the ordinary message that additionally carries the decoded image by pointer. Passing the picture by pointer keeps message delivery cheap even when the output fans out to several nodes: each fan-out branch shares a reference to the same image rather than copying its pixels. The pixels never enter the JSON data bag, so a Debug Print or a saved worksheet only ever shows the lightweight metadata below, never the image bytes.

Any non-image file emits an ordinary message instead, with the same filename / mime-type / size metadata but no preview.

Message data members
MemberDescription
data.filename Base name of the dropped file.
data.path Absolute filesystem path of the dropped file.
data.mimetype Guessed content type, e.g. image/png.
data.image Boolean: true when the file decoded as an image (and the message is a PnImageMessage).
data.width, data.height Pixel dimensions, present for images only.
data.size File size in bytes (omitted when it cannot be read).
data.success Boolean placed in data.success so downstream filters can react to the drop.
data.output Human-readable summary — the filename, with (w×h) appended for images.
Properties
PropertyDescription
area-color Fill colour of the drop-area rectangle (white by default).
border-color Colour of the 1 px frame around the drop area.
