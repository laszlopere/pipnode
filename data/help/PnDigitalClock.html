Digital Clock

Group: Sinks. Type: PnDigitalClock.

Paints a digital clock — a black panel of seven-segment LED digits laid out as HOURS:MINUTES:SECONDS. It is the Countdown node with the days field dropped: the same red-on-black look, colours and segment sizes, but a narrower client area showing only the HH:MM:SS group. Each incoming message must carry a numeric value holding a count of seconds (the Unix epoch the Clock node emits is the canonical feed); the node takes it modulo a day and lights the digits as a 24-hour clock face.

When value is zero or negative, or before any message has arrived, the display shows all zeroes. Being a sink, the node never forwards a message; a non-numeric value is ignored and leaves the current reading untouched. The display repaints only when the visible digits actually change, so a once-a-second feed drives exactly one redraw per second.

The timezone combo shifts the wall-clock readout by a fixed UTC offset, chosen from the same abbreviation-and-name list the Deadline node uses (e.g. CET — Central European Time). Daylight-saving variants are listed as their own offsets (CET vs CEST), so no daylight-saving guessing takes place. The default is Not Set: with no fixed zone selected the node reads the incoming message's timezone member as a bare abbreviation (which the Clock node emits as the local zone, e.g. CEST) and applies the matching offset. An unknown, missing or ambiguous abbreviation falls back to GMT (UTC+0).

Like the Countdown and LED nodes, a Digital Clock snapped onto a worksheet's panel band is mirrored to a live readout in the panel applet, so the same HH:MM:SS face appears on the desktop panel.

SettingDescription
show-labels Draw the HOURS / MINUTES / SECONDS captions above their digit groups.
timezone Timezone the display is shown in, chosen from a list of abbreviations and names. Not Set (the default) defers to the incoming message's timezone member; an unknown or missing abbreviation falls back to GMT.
background-color Fill colour of the panel face behind the digits — the near-black face of an LED clock by default.
segment-color Colour of a lit segment bar — the classic LED red by default.
unlit-segment-color Colour of an unlit segment bar — the dark off-state ghost of a digit, a dim red over the black face by default.
label-color Colour of the HOURS / MINUTES / SECONDS captions — a soft off-white by default.
