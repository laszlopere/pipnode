Bridge Quote

Group: Network. Type: PnBridgeQuote (subclass of PnHttp).

Cross-chain swap-rate monitor. Every period seconds the node asks a real bridge what it would actually pay out for amount units of from, and emits the answer. Where the FX Converter reports a mid-market reference price, this node reports a dealable one: the number carries the provider's spread, its flat network fee and its per-pair limits.

The node is a source — it has no input port. Point two of them at the same pair with different bridge settings and wire both into one Graph to watch the providers diverge. For the same question asked of an amount that arrives on a wire, use Bridge Converter instead.

Providers
BridgeHow the quote is obtained
PulseLN One request to api.pulseln.com/c/prices returns the whole cross-rate matrix, the fee table and the per-asset limits; there is no per-amount endpoint, so the payout is computed locally the same way the swap page computes it. PulseLN publishes its fee, so data.fee is filled in.
ChangeNOW The provider quotes the amount directly through its v1 exchange-amount endpoint, and its limits come from a second call to exchange-range. No API key is needed. The provider's cut is folded into the estimate rather than published, so data.fee is omitted. Note ChangeNOW caps this pair well below PulseLN — an amount over the cap is reported as a readable status naming the actual limit, not as a bare HTTP error.
Properties
PropertyDescription
bridge Which provider to quote: PulseLN or ChangeNOW. Changing it re-points url at that provider's endpoint and drops the cached quote.
from Asset being sold, picked from the same currency list the FX Converter uses, with icons. Neither bridge lists all of them: a pair the selected provider does not trade marks the node as needing configuration rather than failing at fetch time.
to Asset being bought. Same set as from; setting it equal to from marks the node unconfigured.
amount How much of from to quote, default 1,000,000. Bridge pricing is amount-sensitive — a flat network fee dominates a small swap, and both providers enforce a minimum — so the node always quotes a concrete size rather than a single unit.
quote Read-only. The payout: how much to the bridge would deliver for amount, fees included. Persisted with the worksheet.
rate Read-only. quote ÷ amount — what one unit really fetches after the spread and fees. This is the number to compare between bridges. Persisted.
fee Read-only. Provider fee as a fraction (0.014 = 1.4%). Zero means the provider does not publish it separately.
min-amount / max-amount Read-only. The provider's limits, in from units. Zero means unknown or uncapped.
last-update Read-only ISO-8601 timestamp of the last successful quote (“Never” until the first one lands). Cleared the instant bridge, from, to or amount changes. Persisted alongside quote.
status Read-only outcome of the most recent request: OK, Never updated, or Update failed: … with the reason — an offline pool, an amount over the cap, an inactive pair. The same detail goes to the per-node log.
url Endpoint base for the selected bridge, so a self-hosted proxy can be substituted. Normally left alone: picking a bridge sets it.
period Seconds between quotes. Default 300, floor 60; smaller values — from the dialog or by hand-editing a saved worksheet — are silently rounded back up.
Emitted message

One message per tick, on the node's own topic:

FieldDescription
data.value The payout, in to units — the canonical number of the message.
data.rate Effective rate after fees. Compare this between bridges.
data.amount The input amount the quote is for.
data.from / data.to Ticker codes, e.g. PLS and BNB.
data.bridge Provider name, so a merged stream stays attributable.
data.success Whether this tick produced a fresh quote.
data.swappable false when the provider would price this swap but not execute it right now — its payout pool for to is closed, or amount falls outside min-amount…max-amount. data.warning says which. The rate is still reported, and data.success stays true: the price is real, only the execution is blocked.
data.deprecated true whenever the quote cannot be trusted — before the first success, right after a setting changes, or after a failed request. The node also paints the standard error marker on the canvas.
data.output Human-readable summary, or the failure reason.
data.fee, data.min_amount, data.max_amount, data.speed_forecast, data.warning Present only when the provider publishes them — a missing field means “not published”, which is not the same as zero.
Priced but not swappable

A route can be perfectly well priced and still be shut. PulseLN publishes a per-asset pool state and a floating size band (its swap page currently shows “$1 MIN, $1000 MAX”, converted to from units at the live price, so a node can drift out of range with nothing reconfigured). In either case the page still displays the payout and only greys its Swap Now button, saying “Swaps To BNB Temporarily Offline” or “Max Limit Exceeded”.

The node does the same: it reports the rate, sets data.swappable to false, explains why in data.warning, and appends the reason to status. Refusing to quote would blank the graph exactly when a pool drains — which is when a monitor is most worth having. Wire data.swappable into a Filter or Comparator if you want to act only on executable quotes.

Caching

The quote and the timestamp of the last successful fetch round-trip through the worksheet on save/load. Reopening a flow therefore re-emits the cached quote immediately — so Numeric and Graph sinks repaint at once — without firing a request at the provider. Only a missing, stale or unparseable timestamp causes a real fetch.

The quote is a reference quote for amount at the moment it was fetched. Both bridges re-quote when a swap is actually created, and PulseLN's endpoint is undocumented, so treat these numbers as a monitor rather than a promise.
