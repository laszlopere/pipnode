Numeric

Group: Sinks. Type: PnNumeric.

Paints a numeric reading on a row of seven-segment LED digits — the generic-number cousin of the Countdown readout. Each incoming message must carry a numeric value (a double or an int64); the node renders the value as an integer part plus an optional fractional part with a fixed decimal point, and lights a leading minus-sign cell when the value is negative. No captions are drawn — the display is just the LED panel.

The layout is fixed-width and does not jitter across zero: the sign cell is always present (blank when the value is non-negative), the integer part uses leading blanks rather than leading zeroes (" 1.23", not "001.23"), and the last integer cell always lights. When the integer part of the value does not fit in the configured digits cells, every digit reads as a dash — the LED-meter overload indicator. Before any message has arrived the screen reads blank (off-state ghosts only).

Being a sink, the node never forwards a message; a non-finite or non-numeric value is ignored and leaves the current reading untouched. The display repaints only when the stored value actually changes, so a hot source does not drive a redraw faster than the reading moves.

SettingDescription
digits Number of seven-segment cells reserved for the integer part of the value (1–12). Six (the default) shows up to 999999; a value whose integer part does not fit reads as all dashes.
decimal-places Number of cells reserved for the fractional part of the value (0–6). Zero drops the decimal point and the fractional block entirely; two (the default) is the common two-decimal voltmeter look.
background-color Fill colour of the panel face behind the digits — the near-black face of an LED clock by default.
segment-color Colour of a lit segment bar (and the decimal-point dot) — the classic LED red by default.
unlit-segment-color Colour of an unlit segment bar — the dark off-state ghost of a digit, a dim red over the black face by default.
