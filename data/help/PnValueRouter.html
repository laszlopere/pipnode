Value Router

Group: Filters/Gate. Type: PnValueRouter.

Routes each message by a number it carries. It has one input and a configurable number of outputs, each with one rule. The node reads data.value (or the member named by path) from every arriving message and sends the message, unchanged, out of the first output whose rule matches. A message no rule matches is dropped. For example, sorting temperatures:

OutputRuleGets
out1< 0freezing readings
out2between 0 and 250 to 25, both included
out3otherwiseeverything else, including messages without a number

A rule is one of:

  • <, ≤, =, ≠, ≥, > and a number;
  • between a low and a high number, both ends included;
  • otherwise, which matches every message — because the first match wins, put it on the last output to catch what the other outputs did not claim;
  • unused, which matches nothing.

Booleans count as 1 (true) and 0 (false). A message whose member is missing, or holds text rather than a number, matches only an otherwise rule. Each output is labelled with its rule on the worksheet (== 3, 0..25, else).

Use Topic Demux to route on the message topic instead, and Filter when a single yes/no decision needs several conditions or a text comparison.

PropertyDescription
outputs Number of outputs, 2–16. Default 3. Lowering it keeps the rules of the removed outputs, so raising it again brings them back; wires on outputs that no longer exist stop carrying messages.
path The data member holding the number. Default value. A dotted path such as status.level reaches into nested objects.
rules One rule per output, edited in the settings dialog. Saved as a JSON array, for example [{"op":"<","value":0},{"op":"range","low":0,"high":25},{"op":"else"}]; {} is an unused output.
