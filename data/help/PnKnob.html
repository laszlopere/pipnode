Knob

Group: Sources. Type: PnKnob.

Rotary knob source. A dial sits on the right of the node header; spin the mouse wheel while the pointer is over the knob to turn it. Wheel up turns the knob toward max, wheel down toward min, and every notch emits a single message whose data.value carries the knob's current position mapped onto the [min, max] range.

The pointer sweeps 270° with the dead zone at the bottom: fully left (7-o'clock) is min, fully right (5-o'clock) is max, and the midpoint points straight up. One full sweep takes 24 wheel notches, so each notch moves the value by (max − min) / 24; the value is clamped at both end stops.

The two bounds default to 0.0 and 1.0, so out of the box the knob emits a normalised 0…1 value. Writing the min, max or value properties turns the dial without emitting a message — only a wheel rotation emits.

PropertyDescription
min Value emitted when the knob is turned fully left (default 0.0).
max Value emitted when the knob is turned fully right (default 1.0).
value Current knob position, in [min, max]. Writing it turns the dial without emitting; spin the wheel over the knob to turn it and emit in one step.
