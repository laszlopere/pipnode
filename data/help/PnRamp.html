Ramp

Group: Filters/Vectors. Type: PnRamp.

Three-input generator for a large numeric vector — the worked example of Pipnode's vector machinery and the seed of the analog-computer toy. Its inputs from, to and N each carry a numeric value; once all three have arrived the node emits a fresh message whose value is a $pnvector holding the linear ramp: N evenly-spaced samples running from from to to. With N ≥ 2 both endpoints are hit exactly; N == 1 yields the single value from.

The node remembers the last value seen on each input, so a new value on any single input recomputes the ramp from the remembered trio and emits again — drive N alone to change the resolution, drive to alone to stretch the span. Nothing is emitted until all three inputs have carried a number. N is rounded to the nearest whole number of samples and clamped to a sane maximum so a stray huge value cannot exhaust memory; an N below 1 produces nothing. A message without a numeric value is ignored and leaves the remembered inputs untouched.

Feed the result to a Reduce node to fold it back to a scalar, to the Calculator to transform it element-wise (e.g. sin(value)), or to the Debug Print sink to preview it — for example ramp(0, 2π, 256) → sin → reduce max.

InputDescription
from First sample — the value of element 0.
to Last sample — the value of the final element (when N ≥ 2).
N Number of evenly-spaced samples; rounded to the nearest integer and clamped. Below 1 emits nothing.
