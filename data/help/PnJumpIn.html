Jump In

Group: Routing. Type: PnJumpIn.

The entry end of a named connection that carries messages without a wire. Give the flag a tag, and every Jump Out carrying the same tag receives whatever arrives here — the way a schematic uses a global label instead of dragging a net across the page.

Matching is exact and case-sensitive, and it spans the whole document, not just the sheet the flag sits on. That is the point of the node: a wire cannot cross sheets, so jump flags are the supported way to route a signal between them. Reach for a pair when a wire would have to travel most of the way across a worksheet, or when the source and the consumer live on different sheets.

Fan-out and merging both work. Several Jump Out flags sharing one tag each receive their own independent copy of the message, exactly as if they hung off the same output port; several Jump In flags sharing one tag merge onto the same connection. Each delivered copy is a deep clone, so one branch mutating its data bag cannot disturb another.

A flag with no tag, or one whose tag no Jump Out answers, is painted red with a warning mark: it would otherwise swallow messages in silence. Fix it by setting the tag or by adding the missing partner.

Feedback is allowed — a Jump Out may wire back round to a Jump In with the same tag — but a loop that never settles is stopped by the same dispatch-depth limit that guards a wired loop, and the message is dropped.
