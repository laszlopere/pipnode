Round Robin

Group: Filters/Gate. Type: PnRoundRobin.

Deals messages out to its outputs in turn. It has two inputs and a configurable number of outputs. Every message on the in input leaves, unchanged, by the next output: the first message by output 1, the second by output 2, and after the last output the turn wraps back to output 1. With three outputs:

Message1st2nd3rd4th5th
Leaves byout1out2out3out1out2

Exactly one output fires for each message. Use it to spread work over parallel chains (for example several HTTP requests that should not all hit the same server), to alternate between sinks or voices, or for an A/B split.

A message on the reset input makes output 1 the next output again. It sends nothing, so it can be wired back from further down the chain without creating a loop.

PropertyDescription
outputs Number of outputs, 2–16. Default 3. If the next output no longer exists after lowering it, the turn starts again at output 1. Wires on outputs that no longer exist stop carrying messages.

Whose turn it is is runtime state: it is not saved with the worksheet, so a reopened worksheet starts at output 1.
