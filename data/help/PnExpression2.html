Expression 2

Group: Filters. Type: PnExpression2.

Two-input variant of the Expression node. It evaluates an algebraic expression that can combine values from both input ports, e.g. value1 + value2 or (value1 - value2) / value2 * 100.

Each numeric member of the latest message on an input is bound as a variable named after the member with the input number appended: input 1 contributes value1 (and a sibling data.temp as temp1), input 2 contributes value2, temp2, and so on. The node keeps the most recent values seen on each input and recomputes on every incoming message, writing the result to data.value of the message it just received before forwarding it.

PropertyDescription
expression The expression to evaluate. Defaults to value1 + value2.
Language
  • Numbers: 12, 12.3, .5.
  • Variables: any numeric data-bag member of either input, suffixed by the input number, e.g. value1, value2, offset1.
  • Operators: + - * / with the usual precedence, parentheses for grouping, and unary minus.
  • Functions (one argument): sin, cos, tan, log (natural log), log10, exp, sqrt, abs, floor, ceil.
expression: value1 + value2
expression: (value1 - value2) / value2 * 100
expression: sqrt(value1 * value1 + value2 * value2)
Output

On success the node sets data.value to the computed number, data.success to true, and data.output to the formatted result. If the expression cannot be parsed, or it references an input that has not produced a message yet (so e.g. value2 is still unknown), the message is still forwarded but flagged: data.success is set to false and the reason is placed in data.error and data.output, with data.value left unchanged.
