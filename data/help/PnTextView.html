Text View

Group: Sinks. Type: PnTextView.

Sink-with-passthrough that renders the latest data.output string of an incoming message as a read-only multi-line text block in a monospace font — the "terminal pane" complement to Table View's structured rendering of data.table. A wiring like Shell Command → Text View shows the latest run's stdout/stderr verbatim on the canvas.

Defaults are a classic green-on-black terminal scheme; every visual property is exposed so the inspector can repaint a node to e.g. amber-on-black or white-on-blue without code changes.

Each received message replaces the displayed text (the latest snapshot wins, just like Table View); the node does not maintain a scroll-back history. A message that carries no string data.output clears the view to its empty "waiting for output" state — useful for spotting that the upstream producer has stopped emitting parsable text rather than being left with a stale render.

The node carries an output port and re-emits every received message verbatim, so it can sit mid-pipeline as an inline inspector without breaking a downstream consumer. Mouse-wheel scroll over the body moves through long output one line at a time.

Visually the node mirrors Table View exactly (280 px wide header, 173 px body) so a row of mixed view sinks lines up on the worksheet.

PropertyDescription
background-color Fill behind the rendered text. Default: black.
text-color Colour of the rendered text. Default: green.
font-size Monospace font size in pixels (6–48). Default: 12.
