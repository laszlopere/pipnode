Dedup

Group: Filters. Type: PnDedup.

Drops repeats based on a configurable JSON path. The first time a value is seen at key the message is forwarded unchanged; subsequent messages carrying the same value are silently discarded. Each remembered value expires after timeout minutes and is then treated as fresh again. Messages whose key path resolves to nothing (missing member or JSON null) are dropped without being remembered.

PropertyDescription
key JSON path (“/”-separated, e.g. data/value) to the value used as the dedup identity. Resolves against the same root used by Format's placeholders, so topic, id, created and members under data are reachable. Empty key disables the node.
timeout Minutes to remember a value before treating it as fresh again. Defaults to 15.
