RAM

Group: CPU. Type: PnRam.

Addressable read/write memory — a PROM you can write at runtime. It shares PROM's addressing, so the two are drop-in on the read path: the arriving data.value is the address, rounded to the nearest whole cell.

WhenEffect
data.write absent or false Read. The stored word replaces data.value (cells never written read back 0.0), the decoded cell is echoed on data.address, and the message is forwarded — exactly what PROM emits.
data.write true (a boolean, or a number past 0.5) Write. Store data.word (a missing word stores 0) at the address. Emits nothing — a store cannot re-trigger the graph, so RAM can sit in a feedback loop without forming a synchronous cycle.

A message with no numeric data.value drives no address line and is dropped. To write from a worksheet, stamp the three fields with a Set node (for example value = address, word = the datum, write =  true).

PropertyDescription
contents Optional seed image in the same <address> <word> text format as PROM (hex 0x… or decimal, one pair per line, #-comments ignored). Empty by default; runtime writes accumulate on top of it.
