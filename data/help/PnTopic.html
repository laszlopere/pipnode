Topic

Group: Filters. Type: PnTopic.

Rewrites a message's topic to this node's own topic, then forwards the message otherwise untouched. Use it to re-tag a stream mid-flow — for example to give messages a stable topic before they reach an MQTT sink or a subscriber that routes on topic.

The node adds no property of its own. The topic it stamps is the ordinary Topic field every node carries, edited in the node's settings dialog. It supports the usual placeholders — ${nodeclass}, ${nodename}, and ${hostname} — which are resolved at emit time, exactly as when any node stamps its own outgoing topic. Left blank, it falls back to the default /pnode/${nodeclass}/${nodename} template.
