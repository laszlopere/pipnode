AutoInjector

Group: Sources. Type: PnAutoInjector.

Auto-triggered cousin of Injector: emits the same configured payload every period seconds without any external prodding. Useful as a heartbeat for downstream nodes that need a steady signal — driving a Graph with a constant baseline, feeding a Watchdog with the “alive” pulse it expects, or wiring up a stub source while a real probe is still being built. The Injector's click-to-fire button is absent; if you want a manual one-shot, use Injector instead.

The emitted message carries data.value (the configured number), data.output (the configured text) and data.success (the configured boolean) — the same canonical members downstream Graph, Format, Filter and Edge nodes already gate on, so an AutoInjector slots straight into the same wiring an upstream probe would use.

PropertyDescription
output String emitted as data.output on every tick.
value Number emitted as data.value on every tick.
success Boolean emitted as data.success on every tick — lets the node feed an Edge detector or a boolean-aware Filter with a synthetic success/failure pulse.
period Seconds between emissions.
