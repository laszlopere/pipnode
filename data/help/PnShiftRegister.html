Shift Register

Group: CPU. Type: PnShiftRegister.

An open-ended (non-looping) shift register of whole messages. It has one input and a configurable number of outputs, one per stage. Every arriving message goes into stage 1 and pushes the messages already stored one stage along; the message in the last stage falls off the end. The node then sends every filled stage out of its own output:

Messageout1out2out3
1st (A)A——
2nd (B)BA—
3rd (C)CBA
4th (D)DCB

A stage that has not been filled yet stays silent. The whole message is shifted — topic and every data member — not just data.value. The value last sent out of each output is shown beside it on the worksheet.

On every arriving message the outputs fire from the oldest stage to the newest, so out1 fires last. When the stages feed the inputs of a multi-input node such as Calculator 2, the result it computes on the out1 message sees every stage already updated (for example a moving sum of the last N readings). It also recomputes on each earlier output, with some inputs not yet updated, so only its last result for each arriving message is the complete one.

PropertyDescription
outputs Number of stages (and outputs), 2–16. Default 4. Lowering it keeps the newest stages that still fit; wires on outputs that no longer exist stop carrying messages.

The stored messages are runtime state: they are not saved with the worksheet, so a reopened worksheet starts with every stage empty.
