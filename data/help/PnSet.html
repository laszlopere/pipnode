Set

Group: Filters. Type: PnSet.

The complement of Filter. Forwards every incoming message unchanged except that, before forwarding, it sets (or adds) a configured list of members on the message's data bag. Useful for tagging messages with a topic-like marker the next stage can branch on, for stamping a constant endpoint on a synthetic source whose payload would otherwise be missing the field, or for forcing a known success/value through a downstream Format template during a worksheet test.

The properties dialog lays the assignment list out as one row of widgets per assignment, with an Add property button below — the same dynamic-list pattern the Filter editor uses, minus the operator combo (Set assigns rather than compares). Each row is a triple of (path, type, value): the path picks the data-bag member to write, with the same value / success / output / endpoint shortcuts as Filter plus a Custom… entry for any other key, including dotted paths (e.g. foo.bar) which the node materialises by creating intermediate JsonObjects on demand. The type combo (number / string / boolean) drives how the literal is encoded in JSON when the message is forwarded.

An empty assignment list is a no-op pass-through. Existing data-bag members are overwritten; missing ones are added. The list is persisted as a single string property (props) holding the JSON array form so it round-trips through the worksheet save/load path unchanged.
