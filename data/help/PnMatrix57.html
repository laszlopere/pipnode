Matrix57

Group: Sinks. Type: PnMatrix57.

Paints an incoming string on a row of 5×7 dot-matrix LCD cells — the character-LCD cousin of the Segment16 starburst readout. Each cell draws one ASCII glyph as a grid of dark square pixels over the greenish-yellow LCD face, the way an HD44780 character module reads. Distinct upper- and lower-case glyphs are supported; bytes outside the printable ASCII range light no dots in their cell.

Each incoming message must carry a string output — same convention as the Label node. The text is laid out left to right and cropped to the configured cell count; a message with no string output, or with empty output, blanks the row.

The readout can show one or two rows of cells. Lines in the incoming output are split on \n — a real newline character or a backslash-n escape from a Format-style template both work, so a source emitting "line1\nline2" breaks onto the second row instead of printing a literal backslash. Carriage returns are dropped so CRLF output renders cleanly. When the output has more newline-separated lines than the configured row count, the leading lines are dropped and the last lines rows stay on screen.

Increasing the line count does not grow the node: both rows share the same external rectangle, with the dot pitch shrinking to fit. The same applies to the panel-applet mirror, which keeps its panel-row height.

Being a sink, the node never forwards a message. The display repaints only when the visible text actually changes, so a hot source does not drive a redraw faster than the readout content moves.

SettingDescription
cells Number of 5×7 character cells in the row (1–40). Sixteen (the default) is the canonical HD44780 line length; raise it for longer readouts. Text longer than the row is cropped on the right.
lines Number of rows of cells to show (1 or 2). Lines in the incoming output are split on \n; when more lines arrive than the configured count, the leading ones are dropped so the latest output stays on screen. Default 1.
frame-color Fill colour of the plastic bezel framing the LCD — chunky near-black by default, the way a character-LCD module reads.
background-color Fill colour of the LCD face behind the dots — the classic greenish-yellow of a character LCD by default.
pixel-color Colour of a lit dot — near-black by default, the way an LCD pixel reads.
unlit-pixel-color Colour of an unlit dot — the very faint off-state ghost over the face, almost invisible by default.
