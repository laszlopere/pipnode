Register

Group: CPU. Type: PnRegister.

A wire-writable value latch — the accumulator, a general register, or a flag store in a toy-CPU worksheet. It holds one number and has three inputs:

InputEffect
write (0) Latch the arriving data.value. Emits nothing. A message with no usable number is ignored.
read (1) Emit the stored word on data.value (also filling data.output and data.success), reusing the incoming message as the carrier. This is the clock strobe.
reset (2) Store initial. Emits nothing.

The write and reset ports are deliberately silent: a store cannot re-trigger the graph, so a register wired into a feedback loop — a write-back into the same accumulator, a jump target into a program counter — never forms a synchronous cycle. The new value is read back out on the next clock tick instead, which is what keeps a CPU worksheet under the engine's synchronous-dispatch recursion limit. Drive the read input from a Clock or Injector to step the machine.

PropertyDescription
initial Value restored by the reset input, and read out before the first write. Default 0.
