Panel Input

Group: Sources. Type: PnPanelInput.

Driven by an XFCE panel applet — the other half of the panel I/O contract (see Panel Display). A mouse click on the applet is forwarded to the background engine over D-Bus, which makes every Panel Input in the worksheet emit a single message describing the click.

The message identifies the click and the button several ways: its topic is click/<button> (for example click/left or click/right); the standard human-readable summary sits on data.output (for example Applet right mouse button clicked.) — the member a Text to Speech node reads aloud; and the data bag also carries the button number on data.value (1 left, 2 middle, 3 right), the button name on data.button (left / middle / right) and the event name on data.event (click); data.success is true. What the worksheet does with it — route on the topic, speak the output, count it, toggle a Switch, trigger an action — is up to its wiring.

The engine can also drive the node with a plain numeric value (the value property below), carried on data.value with data.success set; a mouse event does not disturb that configured value.

On startup the node emits its current value once, shortly after the worksheet loads, so downstream nodes learn the starting value without waiting for a click. This mirrors how the Knob and Switch report on load; it is a single shot, never re-emitted on a timer.

PropertyDescription
value Numeric value carried on the next emitted message. Restored from the worksheet on load (and announced once on startup); updated each time the panel applet is clicked.
