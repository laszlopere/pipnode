Panel Input

Group: Sources. Type: PnPanelInput.

Driven by an XFCE panel applet — the other half of the panel I/O contract (see Panel Display). When the applet button is clicked, the panel forwards the click to the background engine over D-Bus, which makes this node emit a single message carrying the value on its data.value member (data.success is set true) into the running worksheet.

A left-click sends a fixed “pressed” pulse (data.value = 1.0); what the worksheet does with it — count it, toggle a Switch, trigger an action — is up to its wiring.

On startup the node emits its current value once, shortly after the worksheet loads, so downstream nodes learn the starting value without waiting for a click. This mirrors how the Knob and Switch report on load; it is a single shot, never re-emitted on a timer.

PropertyDescription
value Numeric value carried on the next emitted message. Restored from the worksheet on load (and announced once on startup); updated each time the panel applet is clicked.
