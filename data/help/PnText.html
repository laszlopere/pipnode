Text

Group: Filters. Type: PnText.

Overwrites data.output with a fixed, pre-configured string, regardless of what arrived. Use it to inject a constant message body — a label, a canned notification, a literal payload — into a flow. The rest of the message (its topic, id, and any other data members) passes through untouched, and the message is always forwarded.

The text is edited in a multi-line editor in the property dialog. Leading and trailing newline characters are stripped before the value is written, so a block typed with a stray blank first or last line still yields a clean payload. Interior newlines and non-newline whitespace are preserved.

PropertyDescription
text The fixed string written to data.output on every message. Edited in a multi-line editor; leading and trailing newlines are removed.
