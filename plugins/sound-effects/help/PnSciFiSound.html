Sci-Fi Sound

Group: Sinks. Type: PnSciFiSound.

Sink node that plays a sci-fi sound effect every time a message arrives on its input port. No audio clip is bundled with the plugin — the settings dialog ships a Sound packs tab that lists a few dozen curated Star Trek sound packs (Romulan, Xindi, Klingon, TNG Computer, DS9 Ambience, Doors, Weapons, ...) and lets the user opt into one or more before clicking Download selected. Clips are sourced at runtime from a public fan-site mirror and land under $XDG_DATA_HOME/pipnode/sound-effects/startrek/<Pack>/.

On the Playback tab the user first picks a pack from a combo (only packs with files on disk show up) and then chooses an individual clip from a second combo — the clip property is stored as Pack/basename.mp3 so a worksheet round-trips across machines whose $XDG_DATA_HOME differs. A Preview button auditions the chosen clip on the spot.

On the Sound packs tab the same checkbox grid that drives downloads also feeds Delete selected, which recursively removes the picked packs from disk after a confirmation prompt. A small per-row indicator shows how many clips of each pack are currently on disk so the user can tell at a glance what is already cached.

Playback is dispatched to the first available external player on PATH — mpv, ffplay, gst-play-1.0, mpg123, or paplay (in that order) — so the node handles both .mp3 and .wav clips without the plugin needing to link any audio backend itself. Overlapping messages are dropped while a clip is still playing; a configurable dead-period enforces a minimum gap between two consecutive playbacks even after a clip has finished.

PropertyDescription
clip Relative path of the clip in the cache directory, of the form Pack/basename.mp3. Empty leaves the node unconfigured and paints it with a warning glyph.
dead-period Seconds of silence enforced after each playback.
