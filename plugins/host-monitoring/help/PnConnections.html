Net Connections

Group: Sources. Type: PnConnections.

Auto-triggered probe that counts the host's established TCP connections every period seconds and emits the total as data.value. Only sockets in TCP state ESTABLISHED are counted — TIME_WAIT, CLOSE_WAIT, LISTEN and the various half-closed / transient states are excluded, so the figure tracks connections that are actually alive rather than the wider universe of every entry in the kernel's TCP table.

The count covers every network namespace the probing user can see — LXC / Docker / podman containers each have their own netns, so a naive read of /proc/net/tcp would see only the host's namespace and miss the containers entirely; this node deduplicates processes by the inode of /proc/<pid>/ns/net (via stat -L) and walks each unique namespace's /proc/<pid>/net/tcp{,6} instead, summing rows whose state column equals 01 (the kernel's hex code for ESTABLISHED). To pick up the containers, the probe must run as a user that can read other namespaces' /proc entries — in practice, root over SSH.

When hostname is empty or "localhost" the script runs locally. Any other value is treated as a remote host and the same script is run in one SSH round trip on a worker thread, so an unreachable target cannot freeze the GUI. Passwordless authentication is required (BatchMode=yes), and ConnectTimeout is derived from the period so a dead host can never stall a tick. The cost on the probed host is a fixed handful of forks (ls, stat, sort, cut, awk) regardless of process count, so the probe scales cleanly to a busy server.

The remote login defaults to your ambient SSH setup: the local desktop account and whatever key your ssh-agent or ~/.ssh already provides, trusting the host key on first sight. To reach the host as a different account, on a non-standard port, with a specific identity file, or under a stricter host-key policy, attach an SSH Login credential from the node's SSH Login picker (the auth-profile property). The credential says how to log in; the hostname field still says where. With none selected the node keeps the original passwordless-SSH behaviour.

PropertyDescription
hostname Host whose TCP socket count to read. Defaults to "localhost"; an empty string is treated the same. Any other value is used as the SSH target.
period Seconds between samples.
auth-profile Optional SSH Login credential supplying the remote account, port, identity file and host-key policy. Empty (the default) follows the primary SSH Login profile, or — when none is configured — the node's ambient-key behaviour. Stored in the host vault, never in the worksheet file. Separate from hostname, which still selects where to connect.
