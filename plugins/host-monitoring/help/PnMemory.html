Memory

Group: Host monitoring. Type: PnMemory.

Auto-triggered probe that samples /proc/meminfo every period seconds and emits the memory-used figure as data.value — either a percentage (the default) or an absolute byte count in the chosen unit. "Used" is computed as MemTotal − MemAvailable: the kernel- authoritative "actually unavailable" number, available since Linux 3.14, which accounts for reclaimable caches and slab the way free -h and htop already do. Subtracting MemFree alone (the naive approach pre-3.14 tools took) overstates usage by treating reclaimable page cache as "used" memory, which is why old monitoring dashboards perennially showed every Linux host at "98% memory used" even when idle.

Unlike the I/O nodes, the figure is an instantaneous snapshot rather than a per-second delta, so there is no "warming up" first tick: the very first sample emits a real reading.

The sample comes from /proc/meminfo directly when hostname is empty or "localhost"; any other value is treated as a remote host and the file is fetched over passwordless SSH (ssh -o BatchMode=yes … hostname cat /proc/meminfo) on a worker thread, so an unreachable target cannot freeze the GUI.

Binary multiples. When unit is KByte/MByte/GByte, the divisor is the binary one (1 KByte = 1024 bytes, 1 MByte = 10242, 1 GByte = 10243). This is the convention RAM vendors and tools like free / htop follow: a "32 GB" DIMM is universally understood as 32 GiB (235 bytes), not 32 × 109 bytes. This is a deliberate divergence from Disk I/O and Network I/O, which use decimal (1000-based) multiples to match the disk/network throughput convention.

The emitted message carries data.value (used memory in the configured unit, or used % when unit is %), data.used, data.total, data.available, data.free (all in the configured unit -- in % mode these are also expressed as percentages so a downstream consumer can read them without special-casing the unit), data.percent (the percentage of MemTotal that is currently used — always a percentage regardless of the configured unit, so a downstream filter that wants the saturation curve does not have to special-case %), data.unit (the short string matching the chosen unit), data.host, data.success, and data.output (a one-line human summary). When the SSH probe fails the remote stderr or the spawn error message is folded into data.output so a downstream Debug Print shows the user what went wrong.

The remote login defaults to your ambient SSH setup: the local desktop account and whatever key your ssh-agent or ~/.ssh already provides, trusting the host key on first sight. To reach the host as a different account, on a non-standard port, with a specific identity file, or under a stricter host-key policy, attach an SSH Login credential from the node's SSH Login picker (the auth-profile property). The credential says how to log in; the hostname field still says where. With none selected the node keeps the original passwordless-SSH behaviour.

PropertyDescription
hostname Host whose /proc/meminfo to read. Defaults to "localhost"; an empty string is treated the same. Any other value is used as the SSH target — passwordless authentication must already be set up (BatchMode=yes is forced so the probe never prompts for a password).
unit Output unit for data.value: % (the default — percentage of MemTotal currently in use), or one of B / KByte / MByte / GByte for the absolute used-byte count in binary multiples (1 KByte = 1024 bytes). The chosen short string is also emitted on data.unit so a downstream Graph axis label can pick it up verbatim.
period Seconds between samples. The default of 2 s feels responsive in a downstream Graph without pointlessly hammering an SSH target with a near-static counter (memory pressure typically evolves on a multi- second timescale).
auth-profile Optional SSH Login credential supplying the remote account, port, identity file and host-key policy. Empty (the default) follows the primary SSH Login profile, or — when none is configured — the node's ambient-key behaviour. Stored in the host vault, never in the worksheet file. Separate from hostname, which still selects where to connect.
