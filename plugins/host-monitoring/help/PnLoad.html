System Load

Group: Sources. Type: PnLoad.

Auto-triggered probe that samples the system load average every period seconds and emits the 1-minute figure as data.value alongside its 5- and 15-minute siblings. The sample comes from /proc/loadavg directly when hostname is empty or "localhost"; any other value is treated as a remote host and the sample is fetched over passwordless SSH (ssh -o BatchMode=yes … hostname cat /proc/loadavg) on a worker thread, so an unreachable target cannot freeze the GUI.

The emitted message carries data.value (1-minute average), data.load5, data.load15, data.host (the host that was sampled, normalised to "localhost" for the local path), data.success, and data.output (a one-line summary — either the three readings or the failure reason). When the SSH probe fails the remote stderr or the spawn error message is folded into data.output so a downstream Debug Print shows the user what went wrong.

The remote login defaults to your ambient SSH setup: the local desktop account and whatever key your ssh-agent or ~/.ssh already provides, trusting the host key on first sight. To reach the host as a different account, on a non-standard port, with a specific identity file, or under a stricter host-key policy, attach an SSH Login credential from the node's SSH Login picker (the auth-profile property). The credential says how to log in; the hostname field still says where. With none selected the node keeps the original passwordless-SSH behaviour.

PropertyDescription
hostname Host whose load to read. Defaults to "localhost"; an empty string is treated the same. Any other value is used as the SSH target — passwordless authentication must already be set up (BatchMode=yes is forced so the probe never prompts for a password).
period Seconds between samples.
auth-profile Optional SSH Login credential supplying the remote account, port, identity file and host-key policy. Empty (the default) follows the primary SSH Login profile, or — when none is configured — the node's ambient-key behaviour. Stored in the host vault, never in the worksheet file. Separate from hostname, which still selects where to connect.
