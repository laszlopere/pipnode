Vibrance

Group: Image Processing › Adjust. Type: PnImageVibrance. Plugin: pipnode-image.

Transform node. It adjusts saturation with a weighting toward the less-saturated pixels, so already-vivid colours move less than muted ones, and emits the result as a new PnImageMessage. A positive amount enriches colour, a negative one mutes it toward grey. Hue and value are untouched. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
amount Saturation boost weighted toward less-saturated pixels, -1.0–1.0 (default 0.0). Negative values mute colour.
