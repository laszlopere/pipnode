Edge Enhance

Group: Image. Type: PnImageEdgeEnhance. Plugin: pipnode-image.

Transform node. It applies the full 3×3 eight-neighbour sharpen kernel (centre 9, every neighbour −1) to each colour channel, accentuating edges more aggressively than the cross-shaped Sharpen node while keeping the picture's colours, and emits the result as a new PnImageMessage. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

MemberDescription
