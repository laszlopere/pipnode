Find Edges

Group: Image. Type: PnImageFindEdges. Plugin: pipnode-image.

Transform node. It runs the eight-neighbour Laplacian outline kernel (centre 8, every neighbour −1) on the image's luma, so flat regions go black and every intensity transition lights up, and emits the result as a new PnImageMessage. The eight-neighbour kernel gives a thicker, more closed outline than the four-neighbour Laplacian Edge node. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.
