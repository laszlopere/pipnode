Solarize

Group: Image. Type: PnImageSolarize. Plugin: pipnode-image.

Transform node. It reproduces the Sabattier effect: each colour channel at or above the threshold is inverted (255 − c) while darker values pass through, so highlights flip and the picture takes on the surreal tone-reversed look of an over-exposed print. The result is emitted as a new PnImageMessage. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
threshold Per-channel value at/above which the channel is inverted, 0–255 (default 128). Lower flips more of the image.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Solarize (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
