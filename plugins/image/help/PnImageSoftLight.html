Soft Light

Group: Image Processing › Composite. Type: PnImageSoftLight. Plugin: pipnode-image.

Two-input compositor. Like every node in the Composite subgroup it has two input ports on its left edge: input 0 (the upper tab) and input 1 (the lower tab). Wire an image source to each. The node waits until it holds an image on both ports, then combines them per colour channel and emits the result as a new PnImageMessage: 

    b = base / 255 , o = over / 255
    combined = ((1 - 2×o) × b×b + 2×o×b) × 255
    out      = base × (1 - opacity) + combined × opacity

The Pegtop soft-light curve gives a gentle contrast lift: it lightens where the overlay is light and darkens where the overlay is dark, without the harsh clipping of a hard blend.

The output keeps the geometry of the bigger image (the one with the greater pixel area; a tie keeps input 0). The smaller image is combined into the upper-left corner, and wherever it has run out the bigger image's pixels are copied through unchanged — the images are never scaled. Only the colour channels are combined; the bigger image's alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer on a worker thread, so a large image never freezes the editor; no external program is run. A message that is not an image passes straight through without disturbing the latched inputs.

Properties
PropertyDescription
opacity Mix factor, 0.0–1.0 (default 1.0). 0 keeps only the base image; 1 shows the soft light at full strength.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
