Oil Paint

Group: Image Processing › Stylize. Type: PnImageOilPaint. Plugin: pipnode-image.

Transform node. It applies a classic intensity-histogram oil-paint filter and emits the result as a new PnImageMessage. For each pixel the surrounding (2·radius+1)² neighbourhood is binned into levels intensity buckets; the most-populated bucket's mean colour becomes the output pixel, which flattens fine detail into broad painterly strokes. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
radius Half-width of the sampling window in pixels (window = 2·radius + 1), 1–7 (default 3). Larger gives broader strokes.
levels Number of intensity buckets, 2–64 (default 20). Fewer flattens detail more.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Oil Paint (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
