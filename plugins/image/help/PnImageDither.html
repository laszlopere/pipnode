Dither

Group: Image Processing › Stylize. Type: PnImageDither. Plugin: pipnode-image.

Transform node. It reduces the incoming image to pure black and white using Floyd–Steinberg error diffusion on luma, and emits the result as a new PnImageMessage. Each pixel is rounded to black or white at the 128 midpoint, and the rounding error is spread to the neighbouring pixels that have not yet been processed, so the 1-bit result still reads as continuous tone. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

None.
