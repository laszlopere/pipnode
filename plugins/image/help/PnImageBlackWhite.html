Black & White

Group: Image. Type: PnImageBlackWhite. Plugin: pipnode-image.

Transform node. It reduces the incoming image to two tones: each pixel's Rec. 601 luma is compared against the threshold property — at or above it the pixel becomes pure white, below it pure black — and the result is emitted as a new PnImageMessage. Any alpha channel is preserved. This is a hard threshold, not a dithered halftone.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
threshold Luma cut-off, 0–255 (default 128). Lower keeps more white; higher makes more of the image black.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Black & White (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
