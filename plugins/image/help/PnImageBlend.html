Blend

Group: Image. Type: PnImageBlend. Plugin: pipnode-image.

Two-input transform node. Unlike every other node in this plugin it has two input ports on its left edge: input 0 (the upper tab) and input 1 (the lower tab). Wire an image source to each. The node waits until it holds an image on both ports, then mixes them and emits the result as a new PnImageMessage: 

    out = base × (1 - opacity) + overlay × opacity

The output keeps the geometry of the bigger image (the one with the greater pixel area; a tie keeps input 0). The smaller image is mixed into the upper-left corner, and wherever it has run out the bigger image's pixels are copied through unchanged — the images are never scaled. Only the colour channels are mixed; the bigger image's alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer on a worker thread, so a large image never freezes the editor; no external program is run. A message that is not an image passes straight through without disturbing the latched inputs.

Properties
PropertyDescription
opacity Mix factor, 0.0–1.0 (default 0.5). 0 keeps only the base image; 1 shows only the overlay.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result (those of the bigger input).
data.output Human-readable summary, e.g. Blend (640×480).
data.success Boolean, true on a successful blend.
data.filename, data.path, data.mimetype Carried over from the most recent incoming message when present.
