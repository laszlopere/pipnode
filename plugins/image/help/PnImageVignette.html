Vignette

Group: Image Processing › Stylize. Type: PnImageVignette. Plugin: pipnode-image.

Transform node. It darkens the incoming image towards its corners, leaving the centre untouched, and emits the result as a new PnImageMessage. The falloff is radial: a pixel's distance from the centre (normalised so the corners sit at 1) is squared and scaled by the strength property, so 0 leaves the image unchanged while 1 drives the corners to black. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
strength How strongly the corners are darkened, 0.0–1.0 (default 0.5). 0 = none, 1 = corners go black.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Vignette (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
