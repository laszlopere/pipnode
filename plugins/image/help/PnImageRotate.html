Rotate

Group: Image Processing › Geometry. Type: PnImageRotate. Plugin: pipnode-image.

Geometry node. It turns the incoming image by an arbitrary angle (degrees, counter-clockwise) and emits the result as a new PnImageMessage. The canvas grows so the whole rotated picture fits, so the output dimensions are generally larger than the input and depend on the angle. The source is sampled with bilinear interpolation, and the new corners that fall outside the original are filled with black (transparent when the image has an alpha channel). Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
angle Rotation angle in degrees, −180.0–180.0 (default 0.0). Counter-clockwise; the canvas grows to fit and the new corners are filled with black.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result (the grown, expand-to-fit canvas).
data.output Human-readable summary, e.g. Rotate (724×724).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
