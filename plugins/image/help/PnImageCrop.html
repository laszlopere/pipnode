Crop

Group: Image Processing › Geometry. Type: PnImageCrop. Plugin: pipnode-image.

Geometry node. It cuts out the rectangle given by the x, y, width and height properties and emits that region as a new, smaller PnImageMessage. The origin is clamped inside the source and the size is trimmed to whatever remains, so the rectangle can never run off the edge; if nothing is left to crop the image passes through unchanged. The output dimensions are the cropped rectangle, not the input size. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
x Left edge of the crop rectangle in pixels, 0–100000 (default 0).
y Top edge of the crop rectangle in pixels, 0–100000 (default 0).
width Width of the crop rectangle in pixels, 1–100000 (default 256).
height Height of the crop rectangle in pixels, 1–100000 (default 256).
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result (the cropped rectangle).
data.output Human-readable summary, e.g. Crop (256×256).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
