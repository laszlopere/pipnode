Motion Blur

Group: Image. Type: PnImageMotionBlur. Plugin: pipnode-image.

Transform node. It smears the incoming image along the top-left → bottom-right diagonal, the streak of a camera panned along that line, and emits the result as a new PnImageMessage. The effect is a convolution with an n×n kernel carrying ones down its main diagonal, where n is the length property (forced odd); a length of 1 leaves the image untouched. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
length Diagonal streak length in pixels (the kernel size), 1–25 (default 9). 1 disables the blur.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Motion Blur (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
