Contrast

Group: Image. Type: PnImageContrast. Plugin: pipnode-image.

Transform node. It scales every colour channel away from (or toward) mid-grey 128 — out = (c − 128) · factor + 128 — and emits the result as a new PnImageMessage. A factor of 1 leaves the image unchanged, below 1 flattens it and above 1 steepens it; results are clamped to [0, 255]. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
factor Contrast slope around 128, 0.0–4.0 (default 1.0). 1 is a no-op, <1 flatter, >1 steeper.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Contrast (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
