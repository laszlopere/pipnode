Prewitt Edge

Group: Image. Type: PnImagePrewitt. Plugin: pipnode-image.

Transform node. It detects edges with the Prewitt operator: the image is reduced to luma, the two 3×3 Prewitt kernels measure the horizontal and vertical intensity gradients, and their magnitude sqrt(gx² + gy²) is written out as a grey edge map. The result is emitted as a new PnImageMessage. The uniform (un-weighted) kernel rows make it a touch more sensitive to fine detail than Sobel Edge.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
