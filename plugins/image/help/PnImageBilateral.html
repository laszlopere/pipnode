Bilateral

Group: Image Processing › Blur. Type: PnImageBilateral. Plugin: pipnode-image.

Transform node. It applies an edge-preserving bilateral filter to the incoming image. Each output pixel is a weighted average of its neighbourhood, where a neighbour's weight falls off both with its spatial distance (a Gaussian tied to the window radius) and with how different its colour is from the centre pixel (a Gaussian governed by sigma). Because neighbours across a strong colour edge get tiny weights, flat regions are smoothed while edges stay crisp. Results are clamped to [0, 255] and any alpha channel is preserved. The result is emitted as a new PnImageMessage.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
radius Spatial window radius, 1–7 (default 3). Sets the size of the neighbourhood averaged at each pixel; larger smooths more but costs more.
sigma Colour sigma, 1.0–150.0 (default 30.0). Larger values blend across bigger colour differences (less edge-preserving).
