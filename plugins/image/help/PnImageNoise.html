Add Noise

Group: Image Processing › Stylize. Type: PnImageNoise. Plugin: pipnode-image.

Transform node. It adds a random monochrome offset to every pixel and emits the result as a new PnImageMessage. A single random value is drawn per pixel and applied equally to its red, green and blue channels, so the grain stays grey rather than coloured; the amount property scales how strong the noise is. Results are clamped to [0, 255] and any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
amount Amount of random monochrome noise added per pixel, 0.0–1.0 (default 0.2).
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
