Gaussian Blur

Group: Image. Type: PnImageGaussianBlur. Plugin: pipnode-image.

Transform node. It softens the incoming image with a Gaussian blur and emits the result as a new PnImageMessage. The blur is separable (a horizontal pass followed by a vertical one), so it stays fast even at large radii. The kernel is built from the radius property, with standard deviation sigma = radius / 2; a radius below half a pixel leaves the image untouched. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
radius Blur radius in pixels, 0.0–50.0 (default 2.0). 0 disables the blur.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Gaussian Blur (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
