Unsharp Mask

Group: Image Processing › Sharpen. Type: PnImageUnsharpMask. Plugin: pipnode-image.

Transform node. It sharpens the incoming image using the classic unsharp mask technique: a blurred copy of the image (the “mask”) is subtracted from the original to isolate the edges, and a scaled version of that difference is added back, so edges and fine detail are accentuated. The amount property controls how strongly the edges are boosted and radius sets how wide the blurred mask is. Results are clamped to [0, 255] and any alpha channel is preserved. The result is emitted as a new PnImageMessage.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
amount How strongly edges are accentuated, 0.0–5.0 (default 1.0). 0 leaves the image unchanged; larger values sharpen harder.
radius Blur radius of the mask, 1–15 (default 3). A larger radius softens a wider halo around edges.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Unsharp Mask (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
