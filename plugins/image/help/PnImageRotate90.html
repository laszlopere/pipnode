Rotate 90° CW

Group: Image Processing › Geometry. Type: PnImageRotate90. Plugin: pipnode-image.

Geometry node. It turns the incoming image a quarter-turn clockwise and emits the result as a new PnImageMessage. Because the picture is turned on its side, the output dimensions are the input's width and height swapped (a 640×480 image becomes 480×640). Any alpha channel is preserved. Wire it between a File Drop and a File Viewer to see the effect.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties

None.

Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result (width and height are swapped).
data.output Human-readable summary, e.g. Rotate 90° CW (480×640).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
