Screen

Group: Image Processing › Composite. Type: PnImageScreen. Plugin: pipnode-image.

Two-input compositor with two input ports (input 0, the upper tab, and input 1, the lower tab). Wire an image source to each. Once both ports hold an image the node combines them per colour channel and emits a new PnImageMessage: 

    combined = 255 - (255 - base) × (255 - over) / 255
    out      = base × (1 - opacity) + combined × opacity

Screen is the inverse-multiply and can only lighten: screening with black keeps the base, with white yields white. It is the mirror of Multiply.

The output keeps the geometry of the bigger image (a tie keeps input 0); the smaller image is combined into the upper-left corner and the rest of the canvas keeps the bigger image unchanged — no scaling. Only the colour channels are combined; the bigger image's alpha is preserved.

The pixels are processed in plain C on a worker thread, so a large image never freezes the editor; no external program is run. A non-image message passes straight through without disturbing the latched inputs.

Properties
PropertyDescription
opacity Mix factor, 0.0–1.0 (default 1.0). 0 keeps only the base image; 1 shows the screen at full strength.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result (those of the bigger input).
data.output Human-readable summary, e.g. Screen (640×480).
data.success Boolean, true on success.
data.filename, data.path, data.mimetype Carried over from the most recent incoming message when present.
