Box Blur

Group: Image. Type: PnImageBoxBlur. Plugin: pipnode-image.

Transform node. It applies a box (moving-average) blur over a (2·radius + 1)-pixel-wide window and emits the result as a new PnImageMessage. It is the cheapest blur and gives a flat, slightly boxy softening; for a smoother falloff use Gaussian Blur instead. The blur is separable (horizontal then vertical pass). Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
radius Half-width of the averaging window in pixels, 1–25 (default 1). The window is 2·radius + 1 wide.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Box Blur (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
