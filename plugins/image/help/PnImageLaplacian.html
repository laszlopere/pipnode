Laplacian Edge

Group: Image. Type: PnImageLaplacian. Plugin: pipnode-image.

Transform node. It detects edges with the Laplacian operator: the image is reduced to luma and convolved with the second-derivative 3×3 kernel, which responds to intensity changes in every direction at once. Flat regions go black; transitions of any orientation light up, producing an isotropic edge map. The result is emitted as a new PnImageMessage. Being a single second-derivative pass it is more noise-sensitive than Sobel/Prewitt — pair it with a Gaussian Blur upstream for a cleaner result.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.
