Gamma

Group: Image Processing › Adjust. Type: PnImageGamma. Plugin: pipnode-image.

Transform node. It applies a power-law (gamma) curve to every colour channel of the incoming image and emits the result as a new PnImageMessage. The curve is built once into a 256-entry lookup table from the gamma property: a gamma of 1 leaves the image unchanged, values below 1 darken the midtones and values above 1 lighten them. Highlights and shadows are affected far less than the midtones. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
gamma Gamma exponent, 0.1–5.0 (default 1.0). Values below 1 darken midtones, above 1 lighten them.
Message data members (emitted)
MemberDescription
