Grayscale

Group: Image. Type: PnImageGrayscale. Plugin: pipnode-image.

Transform node. It takes the image carried by an incoming PnImageMessage, replaces every pixel's colour with its Rec. 601 luma (0.299·R + 0.587·G + 0.114·B) so the result is a neutral grey of the same perceived brightness, and emits a new PnImageMessage carrying the processed picture. Any alpha channel is preserved. Wire it between a File Drop and a File Viewer to see the effect.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Grayscale (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
