Saturation

Group: Image. Type: PnImageSaturation. Plugin: pipnode-image.

Transform node. It interpolates each pixel between its Rec.601 luma (a neutral grey) and its original colour — out = luma + (c − luma) · amount — and emits the result as a new PnImageMessage. An amount of 0 collapses the image to greyscale, 1 leaves it unchanged and above 1 boosts the colour; results are clamped to [0, 255]. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
amount Colour scale relative to grey, 0.0–4.0 (default 1.0). 0 = greyscale, 1 = unchanged, >1 more saturated.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Saturation (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
