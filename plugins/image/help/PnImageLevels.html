Levels

Group: Image Processing › Adjust. Type: PnImageLevels. Plugin: pipnode-image.

Transform node. It remaps the tonal range of the incoming image and emits the result as a new PnImageMessage. Input values at or below the black point map to 0 and at or above the white point map to 255; the span between is stretched and reshaped by the gamma midtone curve. The mapping is built once into a 256-entry lookup table and applied to each colour channel. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
black Input black point, 0–254 (default 0). Values at or below it map to 0.
white Input white point, 1–255 (default 255). Values at or above it map to 255.
gamma Midtone power curve across the remapped span, 0.1–5.0 (default 1.0). Below 1 darkens, above 1 lightens.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Levels (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
