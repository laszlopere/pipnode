Crosshatch

Group: Image Processing › Stylize. Type: PnImageCrosshatch. Plugin: pipnode-image.

Transform node. It renders the incoming image as a pen-and-ink crosshatch and emits the result as a new PnImageMessage. Each pixel starts white and is set to black wherever its luma is dark enough for one of four diagonal hatch line sets to fall on its position, so darker tones pick up progressively denser hatching. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

None.
