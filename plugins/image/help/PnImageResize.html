Resize

Group: Image Processing › Geometry. Type: PnImageResize. Plugin: pipnode-image.

Geometry node. It scales the incoming image to the exact width × height given by the properties, using bilinear interpolation, and emits the result as a new PnImageMessage. The aspect ratio is not preserved unless the requested size already matches it. The output dimensions are the requested size, not the input size. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
width Target width of the scaled image in pixels, 1–100000 (default 256).
height Target height of the scaled image in pixels, 1–100000 (default 256).
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result (the requested size).
data.output Human-readable summary, e.g. Resize (256×256).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
