Hue Rotate

Group: Image Processing › Adjust. Type: PnImageHueRotate. Plugin: pipnode-image.

Transform node. It converts every pixel to HSV, adds the degrees property to the hue, converts back to RGB, and emits the result as a new PnImageMessage. Saturation and value are left untouched, so the picture keeps its brightness and vividness while its colours shift around the colour wheel. Greys, which have no defined hue, are unaffected. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
degrees Degrees to rotate every pixel's hue around the colour wheel, -180–180 (default 0.0).
