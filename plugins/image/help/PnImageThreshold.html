Threshold

Group: Image Processing › Stylize. Type: PnImageThreshold. Plugin: pipnode-image.

Transform node. It performs a hard two-tone conversion: each pixel's Rec.601 luma is compared to the level cutoff, becoming pure white at or above it and pure black below it, and the result is emitted as a new PnImageMessage. Unlike Dither there is no error diffusion, so the output is a crisp silhouette. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
level Luma cutoff, 0–255 (default 128). Pixels at or above become white, below become black.
