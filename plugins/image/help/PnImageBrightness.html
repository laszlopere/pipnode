Brightness

Group: Image. Type: PnImageBrightness. Plugin: pipnode-image.

Transform node. It multiplies every colour channel of the incoming image by the factor property and emits the result as a new PnImageMessage. A factor of 1 leaves the image unchanged, below 1 darkens it and above 1 brightens it; results are clamped to [0, 255]. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
factor Channel multiplier, 0.0–4.0 (default 1.0). 1 is a no-op, <1 darker, >1 brighter.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Brightness (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
