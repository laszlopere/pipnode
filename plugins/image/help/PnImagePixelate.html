Pixelate

Group: Image Processing › Stylize. Type: PnImagePixelate. Plugin: pipnode-image.

Transform node. It splits the incoming image into a grid of square blocks block pixels on a side, averages the colour within each block, and paints the whole block that mean — the classic mosaic or "censor" look — emitting the result as a new PnImageMessage. Blocks at the right and bottom edges are clipped to the image bounds. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.
