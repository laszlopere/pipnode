Histogram Equalize

Group: Image Processing › Adjust. Type: PnImageHistEqualize. Plugin: pipnode-image.

Transform node. It spreads the image's luma across the full tonal range so a flat, low-contrast picture gains contrast, and emits the result as a new PnImageMessage. A luma histogram is built over every pixel, its cumulative distribution is mapped onto [0, 255], and each pixel is scaled by the ratio of its new luma to its old one — which equalizes brightness while keeping hue. Any alpha channel is preserved. The node has no properties.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

None.
