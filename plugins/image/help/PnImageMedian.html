Median

Group: Image. Type: PnImageMedian. Plugin: pipnode-image.

Transform node. It replaces every colour channel with the median of its (2·radius+1)² neighbourhood and emits the result as a new PnImageMessage. This rank filter removes salt-and-pepper / speckle noise while keeping edges far crisper than an averaging blur would. Any alpha channel is preserved.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties
PropertyDescription
radius Half-width of the square sampling window in pixels (window = 2·radius + 1), 1–5 (default 1). Larger removes more noise but is slower.
Message data members (emitted)
MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
data.output Human-readable summary, e.g. Median (640×480).
data.success Boolean, true on a successful transform.
data.filename, data.path, data.mimetype Carried over from the incoming message when present.
