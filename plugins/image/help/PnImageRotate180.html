Rotate 180°

Group: Image Processing › Geometry. Type: PnImageRotate180. Plugin: pipnode-image.

Geometry node. It turns the incoming image a half-turn — upside down — and emits the result as a new PnImageMessage. The output keeps the same dimensions as the input. Any alpha channel is preserved. Wire it between a File Drop and a File Viewer to see the effect.

The pixels are processed in plain C against the raw image buffer; no external program is run. A message that is not an image passes through unchanged.

Properties

None.

MemberDescription
data.image Always true — the output is an image message.
data.width, data.height Pixel dimensions of the result.
