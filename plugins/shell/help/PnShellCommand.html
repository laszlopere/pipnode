Shell Command

Group: Shell. Type: PnShellCommand.

Auto-triggered runner that executes the configured one-line shell command every period seconds and emits one message per run on its output port. The command is spawned via /bin/sh -c on a worker thread so the GUI never blocks on slow commands; pipes, redirections, and shell variable expansion all work as they would on the terminal.

The emitted message carries:

  • data.success — true when the command exited with status 0, false otherwise.
  • data.output — the combined stdout and stderr of the run, verbatim. JSON serialisation of the message escapes embedded newlines as the standard \n sequence on its own, so the value survives transport as one logical string; downstream Debug Print nodes in text mode render the raw bytes (i.e. multi-line output prints across multiple lines).

While shell-command is empty the node turns red, shows a warning glyph, and skips its triggers entirely.

PropertyDescription
shell-command One-line shell command to execute. Required.
host Where to run the command. Default localhost (and the synonyms 127.0.0.1, ::1, empty string) runs locally. Any other value (a hostname or user@host) routes the run through ssh -o BatchMode=yes -o ConnectTimeout=5; a working passwordless key for that host is required since BatchMode disables every interactive prompt.
period Seconds between executions.
