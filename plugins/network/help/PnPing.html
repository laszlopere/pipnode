Network Ping

Group: Network. Type: PnPing.

Auto-triggered probe that sends one ICMP echo to the configured host every period seconds and emits the result on its output port. The actual probe spawns the system ping utility on a worker thread, so the GUI never blocks on slow or unreachable targets.

The emitted message carries data.success (whether a reply was received) and data.output (a one-line summary). While host is empty the node turns red, shows a warning glyph, and skips its triggers entirely.

PropertyDescription
host Hostname or IP to probe. Required.
period Seconds between probes.
