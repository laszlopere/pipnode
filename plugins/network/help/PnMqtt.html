MQTT Source

Group: Network. Type: PnMqtt.

Source-only node that connects to an MQTT broker, subscribes to a topic filter, and emits one PnMessage for every PUBLISH the broker delivers. Designed to drop onto a worksheet, point at a broker, and start feeding pub/sub data into the rest of the pipeline — no input port; the output port carries the rebuilt message.

Connection

The url property is the broker address. Three URL shapes are accepted:

  • tcp://host[:port] — plain MQTT, default port 1883.
  • ssl://host[:port] or mqtts://host[:port] — MQTT over TLS, default port 8883. The broker's certificate is verified against the system trust store; install your CA in the OS trust store when using a private PKI.
  • A bare host[:port] with no scheme, treated as plain TCP.

The default URL is tcp://mqtt.homelab.local:1883. The node connects asynchronously, retries on failure with a 1 s to 30 s exponential back-off, and re-subscribes on every reconnect — so a transient broker outage recovers without operator intervention.

Subscription

The subscribe-topic property is the MQTT topic filter. Standard MQTT wildcards apply: + matches a single level, # matches the remainder. Defaults to # so the node produces output as soon as it connects. The qos property selects the requested QoS level (0, 1 or 2); the broker may downgrade.

Authentication

Set username (and optionally password) when the broker enforces auth. With username empty the node connects anonymously. client-id is normally left empty and libmosquitto generates a random id; pin a fixed id when the broker enforces an ACL by client id.

Emitted message

Each PUBLISH lands as a message whose envelope topic is mqtt/<mqtt-topic> — e.g. an MQTT publish on tele/sonoff37/SENSOR arrives with topic = "mqtt/tele/sonoff37/SENSOR", so a downstream Filter can route on the envelope alone (match mqtt/tele/+/SENSOR, mqtt/home/#, etc.) without having to dig into the data bag. The data bag carries:

FieldTypeMeaning
data.payloadvaries Parsed JSON value when the payload is valid JSON (object, array, number, string, bool, null) — so a Tasmota-style {"AM2301":{"Temperature":22.6,...}} lands as a proper nested object the downstream Filter / Format nodes can pluck values out of with a path like payload.AM2301.Temperature. Falls back to the raw UTF-8 string when the payload is not valid JSON. Empty string when the payload is binary, non-UTF-8, or empty.
data.valuenumber Numeric coercion of the payload, present only when the payload parses as a single number (so a Graph downstream works without an extra Format/Filter pair). Covers both bare-text 23.5 and JSON-number 23.5.
data.outputstring Short "MQTT message on topic" summary for log views. The payload itself is not inlined (it can be megabytes — image base64, firmware blobs, batched telemetry); a reader who wants it can drop the Debug node into JSON mode or wire a Format template.
data.successboolean Always true; presence of the message itself implies a successful round-trip.
data.qosint QoS the publish arrived at.
data.retainedboolean Whether the broker delivered this from its retained-message store rather than as a fresh publish.
Properties
PropertyDescription
url Broker URL. Defaults to tcp://mqtt.homelab.local:1883.
subscribe-topic MQTT topic filter to subscribe to. Defaults to #.
username MQTT username; empty means anonymous.
password MQTT password; only sent when username is set.
client-id MQTT client identifier; empty asks libmosquitto to generate a random one.
qos Subscription QoS level (0..2); defaults to 0.
Quick test
mosquitto_pub -h mqtt.homelab.local -t test/hello -m '23.5'
mosquitto_pub -h mqtt.homelab.local -t test/sensor -m '{"t":22.6,"h":41.2}'

With the default subscription subscribe-topic = "#" the first publish lands as PnMessage{ topic="mqtt/test/hello", data.payload=23.5, data.value=23.5, data.output="MQTT message on test/hello" }; the second as PnMessage{ topic="mqtt/test/sensor", data.payload={t:22.6, h:41.2}, data.output="MQTT message on test/sensor" } — note the payload is a real nested object, not an escaped JSON string, so a downstream Format can read payload.t directly.
