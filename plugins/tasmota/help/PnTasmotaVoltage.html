Tasmota Voltage

Group: Tasmota. Type: PnTasmotaVoltage. Inherits from Analog Meter.

Sink node that paints a classic AC voltmeter: a square plastic case with an inset paper-white face, a diagonal arc of black ticks running from 0 V at the lower-left up to the configured full-scale value at the upper-right, a long black needle pivoted at the lower-right and a “V” unit glyph stacked over the IEC AC sine-wave symbol in the upper-left corner. The needle reads ENERGY.Voltage off every Tasmota tele/<device>/SENSOR publish from the configured device.

Configuration
PropertyDescription
switch-name Tasmota device name the meter listens for. Matched against the second-to-last segment of each incoming topic, so sonoff37 accepts publishes on mqtt/tele/sonoff37/SENSOR and silently drops everything else. An empty field rejects every message and the needle stays parked.
min-value / max-value Defaults to 0 V .. 240 V, the typical scale on a domestic single-phase mains voltmeter.
Wiring example
MQTT Source (topic = tele/+/SENSOR)
    → Tasmota Voltage (switch-name = sonoff37)

Drop one Tasmota Voltage per device and fan the same MQTT source into each — the per-meter switch-name field handles the demultiplexing without needing a separate Filter rule. The meter accepts every other Analog Meter property (scale colours, accuracy class, tick density) so a worksheet can customise the look without subclassing.
