Tasmota Status

Group: Tasmota. Type: PnTasmotaStatus.

Pass-only filter that lets a message through when its envelope topic identifies a Tasmota STATUS reply, and drops everything else. Use it to split a single broker subscription into a STATUS-handling branch and a telemetry branch without writing a custom Filter predicate.

What gets through

A message is forwarded when the last segment of its topic starts with the literal text STATUS. That covers both the bare omnibus reply (stat/<device>/STATUS, emitted in response to cmnd/<device>/Status) and every numeric variant Tasmota produces:

  • stat/<device>/STATUS — firmware/version dump
  • stat/<device>/STATUS5 — network info (IP, hostname, MAC)
  • stat/<device>/STATUS11 — current state
  • … and the rest of the STATUS0..STATUS13 family

Only the last topic segment is inspected, so any leading family prefix in front of stat/<device>/ does not interfere with the match.

Output shape

Forwarded messages are emitted unchanged: the envelope topic, id and data bag survive the filter byte-for-byte, so a downstream node sees exactly what the upstream producer (typically MQTT Source parsing the JSON STATUS payload) emitted.

Wiring example
MQTT Source (topic = stat/+/STATUS+ ; or just stat/#)
    → Tasmota Status
        → Debug View                 (inspect the STATUS reply)
        → Format / Filter / Graph    (further per-field handling)
