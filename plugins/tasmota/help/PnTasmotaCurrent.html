Tasmota Current

Group: Tasmota. Type: PnTasmotaCurrent. Inherits from Analog Meter.

Sink node that paints a classic AC ammeter: same panel-meter silhouette as Tasmota Voltage but with an “A” unit glyph above the AC sine-wave symbol and a default 0 A .. 16 A scale matching the rated current of the typical Sonoff Pow / Pow R2 relay. The needle reads ENERGY.Current off every Tasmota tele/<device>/SENSOR publish from the configured device.

Configuration
PropertyDescription
switch-name Tasmota device name the meter listens for — see Tasmota Voltage for the matching rule.
min-value / max-value Defaults to 0 A .. 16 A. Raise the upper bound for a three-phase contactor or for an industrial meter wired through a current transformer.
