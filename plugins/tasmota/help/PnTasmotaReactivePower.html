Tasmota Reactive Power

Group: Tasmota. Type: PnTasmotaReactivePower. Inherits from Analog Meter.

Sink node that paints an analog var-meter reading ENERGY.ReactivePower — Q = V⋅I⋅sinφ — off every Tasmota tele/<device>/SENSOR publish from the configured device. The unit glyph is “var” (volt-amperes reactive) with no current-type symbol: reactive power has no DC equivalent.

Configuration
PropertyDescription
switch-name Tasmota device name the meter listens for — see Tasmota Voltage for the matching rule.
min-value / max-value Defaults to 0 var .. 3680 var. Drop the lower bound below zero for a meter that should signal capacitive (negative Q) as well as inductive (positive Q) loads.
