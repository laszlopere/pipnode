Tasmota Humidity

Group: Tasmota. Type: PnTasmotaHumidity.

Filter / transformer node that watches an upstream MQTT stream for Tasmota SENSOR publishes, picks the humidity reading out of the per-sensor JSON wrapper, and re-emits the message with the reading promoted to the standard data.value / data.unit / data.device shape every other node in the palette already speaks.

What gets through

Wire a MQTT Source (or any other producer that emits data.payload as a JSON object) into the input port. The node looks for a numeric Humidity member in the payload — first at the top level, then in each direct child object (Tasmota wraps the reading in a per-sensor object such as AM2301 or DHT22). Messages whose payload does not contain a Humidity member are dropped silently.

Output shape

The emitted message preserves the input's envelope topic and id and mutates only the data bag:

  • data.value — the humidity reading as a JSON number, in units of percent relative humidity.
  • data.unit — always "%". Tasmota does not carry a per-message unit for humidity (it is universally relative humidity), so the node hard-codes the string here for symmetry with the Temperature node.
  • data.device — the device id parsed from the MQTT topic (the second-to-last segment, e.g. "tasmota13" from "mqtt/tele/tasmota13/SENSOR"). Omitted when the topic has fewer than three segments.
  • data.output — one-line summary suitable for a Debug pane: "tasmota13: humidity 41.3%".
  • data.success — true.
