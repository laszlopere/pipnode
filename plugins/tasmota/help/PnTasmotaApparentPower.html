Tasmota Apparent Power

Group: Tasmota. Type: PnTasmotaApparentPower. Inherits from Analog Meter.

Sink node that paints an analog volt-ampere meter reading ENERGY.ApparentPower — S = V⋅I — off every Tasmota tele/<device>/SENSOR publish from the configured device. The unit glyph is “VA” with no current-type symbol: apparent power only has a meaningful AC reading to begin with.

Configuration
PropertyDescription
switch-name Tasmota device name the meter listens for — see Tasmota Voltage for the matching rule.
min-value / max-value Defaults to 0 VA .. 3680 VA.
