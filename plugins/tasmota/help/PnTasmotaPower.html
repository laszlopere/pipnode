Tasmota Power

Group: Tasmota. Type: PnTasmotaPower. Inherits from Analog Meter.

Sink node that paints an analog wattmeter reading ENERGY.Power — real power P = V⋅I⋅cosφ — off every Tasmota tele/<device>/SENSOR publish from the configured device. The unit glyph is “W” and the IEC current-type symbol is suppressed: power is a derived quantity whose AC / DC sense is already covered by the matching Tasmota Voltage / Tasmota Current meters.

Configuration
PropertyDescription
switch-name Tasmota device name the meter listens for — see Tasmota Voltage for the matching rule.
min-value / max-value Defaults to 0 W .. 3680 W (16 A × 230 V single-phase ceiling).
