Tasmota Power Factor

Group: Tasmota. Type: PnTasmotaPowerFactor. Inherits from Analog Meter.

Sink node that paints an analog cosφ gauge reading ENERGY.Factor — the dimensionless ratio P / S — off every Tasmota tele/<device>/SENSOR publish from the configured device. The unit label is the literal string “cos φ” and the IEC current-type symbol is suppressed: power factor describes the phase between voltage and current, so an AC / DC indicator would be self-referential.

Configuration
PropertyDescription
switch-name Tasmota device name the meter listens for — see Tasmota Voltage for the matching rule.
min-value / max-value Defaults to 0 .. 1, the natural cosφ range.
